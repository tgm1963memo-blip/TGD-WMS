# อัตราค่าบริการลูกค้า (Customer Service Rates)

## วัตถุประสงค์
หน้านี้ให้ผู้ดูแลระบบกำหนดอัตราค่าบริการสำหรับแต่ละลูกค้าและแต่ละสินค้า เพื่อใช้คำนวณใบแจ้งหนี้รายเดือน

## ผู้ใช้งาน
- System Administrator (admin)
- Accounting

## สิทธิ์ที่ต้องการ
- **Admin** หรือ **Accounting**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Administration | อัตราค่าบริการ |
| URL | `/admin/service-rates` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: เลือกลูกค้าและสินค้า
- **เลือกลูกค้า** (บังคับ) — เลือกก่อน
- **เลือกสินค้า** — กรองตามลูกค้าที่เลือก

### ส่วนที่ 2: ตารางอัตราค่าบริการ

| คอลัมน์ | ความหมาย |
|---------|---------|
| ประเภทบริการ | ประเภทค่าบริการ (Badge สี) |
| อัตรา | ราคาต่อหน่วย |
| ฐานคิด (Unit Basis) | หน่วยที่ใช้คำนวณ |
| หมายเหตุ | ข้อมูลเพิ่มเติม |
| สถานะ | ใช้งาน / ปิดใช้งาน |
| การดำเนินการ | แก้ไข |

---

## ประเภทบริการ

| รหัส | ชื่อ | ความหมาย |
|------|------|---------|
| STORAGE | ค่าเก็บ | ค่าเก็บรักษาสินค้าในคลัง |
| HANDLING_IN | ค่าเข้า | ค่าดำเนินการรับสินค้าเข้า |
| HANDLING_OUT | ค่าออก | ค่าดำเนินการส่งสินค้าออก |
| LABEL | ค่าสติ๊กเกอร์ | ค่าพิมพ์และติดป้าย |
| FREEZING | ค่าแช่แข็ง | ค่าบริการแช่แข็งพิเศษ |
| OTHER | อื่นๆ | ค่าบริการอื่นนอกรายการ |

---

## หน่วยคิดค่าบริการ (Unit Basis)

| รหัส | ความหมาย |
|------|---------|
| PER_KG | ต่อกิโลกรัม |
| PER_PALLET | ต่อพาเลท |
| PER_BOX | ต่อกล่อง |
| PER_LOT | ต่อล็อต |
| PER_PIECE | ต่อชิ้น |

---

## ขั้นตอนเพิ่มอัตราค่าบริการ

**ขั้นตอนที่ 1:** เลือก **ลูกค้า** และ **สินค้า** (ถ้ากำหนดเฉพาะสินค้า)

**ขั้นตอนที่ 2:** กด **เพิ่มอัตราค่าบริการ**

**ขั้นตอนที่ 3:** กรอกข้อมูล:
- **ประเภทบริการ** — เลือกจากรายการ (ปิดแก้ไขหลังสร้าง)
- **อัตรา** — ราคาต่อหน่วย (ตัวเลข)
- **หน่วยคิด** — PER_KG / PER_PALLET / ฯลฯ
- **หมายเหตุ** — ข้อมูลเพิ่มเติม

**ขั้นตอนที่ 4:** กด **บันทึก**

---

## กฎทางธุรกิจ

1. ประเภทบริการไม่สามารถเปลี่ยนหลังสร้างแล้ว — ต้องลบและสร้างใหม่
2. แต่ละลูกค้า-สินค้า มีได้ทีละ 1 อัตราต่อประเภทบริการ
3. อัตราค่าบริการใช้คำนวณใบแจ้งหนี้รายเดือนอัตโนมัติ
4. ต้องกำหนดอัตรา **STORAGE** และ **HANDLING_IN/OUT** ก่อนที่ระบบจะคำนวณบิลได้ถูกต้อง

---

## คำถามที่พบบ่อย

**ถาม:** ลูกค้าคนเดียวกัน สินค้าต่างกัน ราคาต่างกันได้ไหม?
**ตอบ:** ได้ เลือกสินค้าในขั้นตอนแรก แล้วกำหนดอัตราเฉพาะสินค้านั้น

**ถาม:** เปลี่ยนอัตราค่าบริการกลางเดือน ราคาจะใช้อัตราไหน?
**ตอบ:** ระบบใช้อัตราที่มีผลในเวลาที่เกิดธุรกรรม ติดต่อฝ่ายบัญชีเพื่อตรวจสอบ
