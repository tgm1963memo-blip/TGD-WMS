# แคตตาล็อกสินค้าลูกค้า (Customer Product Catalog)

## วัตถุประสงค์
หน้านี้ให้ผู้ดูแลระบบจัดการรายการสินค้าของแต่ละลูกค้า เพื่อใช้ในการรับฝาก เบิกสินค้า และออกรายงาน

## ผู้ใช้งาน
- System Administrator (admin)
- Warehouse Manager

## สิทธิ์ที่ต้องการ
- **Admin** หรือ **Warehouse Manager**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Administration | แคตตาล็อกสินค้า |
| URL | `/admin/product-catalog` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: การค้นหาและกรอง
- ค้นหาสินค้าตามชื่อหรือรหัส
- กรองตามลูกค้า

### ส่วนที่ 2: ตารางสินค้า

| คอลัมน์ | ความหมาย |
|---------|---------|
| ลูกค้า | รหัสและชื่อลูกค้า |
| รหัสสินค้าลูกค้า | รหัสที่ลูกค้าใช้ |
| ชื่อสินค้า | ชื่อสินค้า |
| รหัสสินค้าภายใน | รหัสที่คลังใช้ |
| หน่วย (UOM) | หน่วยนับ |
| อุณหภูมิ | FROZEN / CHILLED / AMBIENT |
| ฐานคิดค่าเก็บ | WEIGHT / PALLET |
| สถานะ | ใช้งาน / ปิดใช้งาน |
| การดำเนินการ | แก้ไข / ปิดใช้งาน |

### ส่วนที่ 3: ปุ่มหลัก
- **สร้างสินค้า** — เพิ่มสินค้าใหม่
- **Export Excel** — ดาวน์โหลดรายการสินค้าเป็น Excel
- **Import Excel** — นำเข้าสินค้าจาก Excel
- **Download Template** — ดาวน์โหลดแม่แบบ Excel

## ฟอร์มสร้าง/แก้ไขสินค้า

| ฟิลด์ | บังคับ | คำอธิบาย |
|-------|--------|---------|
| ลูกค้า | ใช่ | เลือกลูกค้าที่เป็นเจ้าของสินค้า (ปิดแก้ไขหลังสร้าง) |
| รหัสสินค้าลูกค้า | ใช่ | รหัสที่ลูกค้าใช้เรียกสินค้านี้ |
| ชื่อสินค้า | ใช่ | ชื่อสินค้า |
| รหัสสินค้าภายใน | ไม่ | รหัสที่คลังใช้อ้างอิงภายใน |
| หน่วยนับ (UOM) | ใช่ | กก. / กล่อง / ถุง / ชิ้น / แพ็ค / โหล / ลัง (หรือกำหนดเอง) |
| ประเภทอุณหภูมิ | ใช่ | FROZEN / CHILLED / AMBIENT |
| ฐานคิดค่าเก็บ | ใช่ | WEIGHT (คิดต่อ กก.) หรือ PALLET (คิดต่อพาเลท) |
| น้ำหนักต่อกล่อง (กก.) | ไม่ | น้ำหนักเฉลี่ยต่อกล่อง |
| สารก่อภูมิแพ้ (Allergen) | ไม่ | มี / ไม่มี + รายละเอียด |
| หมายเหตุ | ไม่ | ข้อมูลเพิ่มเติม |

## ขั้นตอนการเพิ่มสินค้าใหม่

**ขั้นตอนที่ 1:** กด **สร้างสินค้า**

**ขั้นตอนที่ 2:** เลือก **ลูกค้า** เจ้าของสินค้า

**ขั้นตอนที่ 3:** กรอก **รหัสสินค้าลูกค้า** และ **ชื่อสินค้า**

**ขั้นตอนที่ 4:** เลือก **ประเภทอุณหภูมิ** และ **ฐานคิดค่าเก็บ**

**ขั้นตอนที่ 5:** กรอกข้อมูลเพิ่มเติม (น้ำหนักต่อกล่อง, Allergen)

**ขั้นตอนที่ 6:** กด **บันทึก**

---

## ขั้นตอน Import Excel

**ขั้นตอนที่ 1:** กด **Download Template** เพื่อดาวน์โหลดแม่แบบ

**ขั้นตอนที่ 2:** กรอกข้อมูลสินค้าในไฟล์ Excel ตาม Template

**ขั้นตอนที่ 3:** กด **Import Excel** และเลือกไฟล์

**ขั้นตอนที่ 4:** ตรวจสอบผลการนำเข้า

---

## กฎทางธุรกิจ

1. **ลูกค้า** ไม่สามารถเปลี่ยนหลังสร้างสินค้าแล้ว
2. รหัสสินค้าลูกค้าต้องไม่ซ้ำกันภายในลูกค้าเดียวกัน
3. **FROZEN** = แช่แข็ง อุณหภูมิต่ำกว่า -18°C; **CHILLED** = แช่เย็น 0-4°C; **AMBIENT** = ทั่วไป
4. **ฐานคิดค่าเก็บ** กำหนดว่าค่าบริการคิดต่อน้ำหนัก (กก.) หรือต่อพาเลท

---

## คำถามที่พบบ่อย

**ถาม:** ลูกค้ามีสินค้าหลายร้อยรายการ ต้องป้อนทีละรายการไหม?
**ตอบ:** ใช้ Import Excel — ดาวน์โหลด Template กรอกข้อมูลและนำเข้าครั้งเดียว

**ถาม:** สินค้าที่ปิดใช้งาน (Deactivate) แล้ว ข้อมูลเก่าหายไปไหม?
**ตอบ:** ข้อมูลเก่าคงอยู่ สินค้าแค่ไม่ปรากฏในรายการให้เลือกใหม่อีก
