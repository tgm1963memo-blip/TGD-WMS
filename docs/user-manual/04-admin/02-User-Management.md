# การจัดการผู้ใช้ (User Management)

## วัตถุประสงค์
หน้านี้ให้ผู้ดูแลระบบสร้าง แก้ไข และจัดการบัญชีผู้ใช้งานทั้งหมดในระบบ

## ผู้ใช้งาน
- System Administrator (admin)

## สิทธิ์ที่ต้องการ
- **Admin** หรือสูงกว่า

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Administration | จัดการผู้ใช้งาน |
| URL | `/admin/users` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ปุ่มหลัก
- **Create User** — สร้างบัญชีผู้ใช้ใหม่

### ส่วนที่ 2: ตารางรายชื่อผู้ใช้

| คอลัมน์ | ความหมาย |
|---------|---------|
| Email | อีเมล (ชื่อผู้ใช้สำหรับเข้าสู่ระบบ) |
| ชื่อที่แสดง (Display Name) | ชื่อที่ปรากฏในระบบ |
| บทบาท (Role) | ระดับสิทธิ์ |
| ลูกค้า | ลูกค้าที่ผู้ใช้ผูกกับ (กรณีบัญชีลูกค้า) |
| สถานะบัญชีระบบ | Linked / Pending (เชื่อมต่อแล้ว / รอยืนยัน) |
| สถานะ | ใช้งานได้ / ปิดใช้งาน |
| การดำเนินการ | ปุ่มแก้ไข / เปิด-ปิดใช้งาน |

---

## บทบาทที่กำหนดได้

| บทบาท | ระดับสิทธิ์ | ใช้สำหรับ |
|--------|-----------|---------|
| admin | สูงสุด | ผู้ดูแลระบบ |
| warehouse_manager | ระดับ 3 | ผู้จัดการคลัง |
| warehouse_admin | ระดับ 2.5 | ธุรการคลัง |
| warehouse_staff | ระดับ 2 | เจ้าหน้าที่คลัง |
| accounting | ระดับ 4 | บัญชี / การเงิน |
| viewer | ระดับ 1 | ผู้ชม (อ่านอย่างเดียว) |
| customer_user | พิเศษ | พอร์ทัลลูกค้า |

---

## ขั้นตอนการสร้างผู้ใช้ใหม่

**ขั้นตอนที่ 1:** กด **Create User**

**ขั้นตอนที่ 2:** กรอกข้อมูล:
- **Email** (จำเป็น) — อีเมลสำหรับเข้าสู่ระบบ
- **Display Name** (จำเป็น) — ชื่อที่แสดงในระบบ
- **PIN มือถือ** — PIN 6 หลักสำหรับใช้เครื่องมือถือ (handheld)
- **รหัสผ่าน** — อย่างน้อย 8 ตัวอักษร (สำหรับผู้ใช้ใหม่)
- **บทบาท** — เลือกระดับสิทธิ์
- **ลูกค้า** — (แสดงเมื่อบทบาทเป็น customer_user)

**ขั้นตอนที่ 3:** กด **Save**

---

## ขั้นตอนแก้ไขผู้ใช้

**ขั้นตอนที่ 1:** กด **Edit** ที่แถวผู้ใช้ที่ต้องการ

**ขั้นตอนที่ 2:** แก้ไขข้อมูลที่ต้องการ (Email ไม่สามารถเปลี่ยนได้)

**ขั้นตอนที่ 3:** กด **Save**

---

## ปุ่มทั้งหมด

| ปุ่ม | เงื่อนไข | คำอธิบาย |
|------|---------|---------|
| Create User | เสมอ | สร้างผู้ใช้ใหม่ |
| Edit | เสมอ | แก้ไขข้อมูลผู้ใช้ |
| Activate | ปิดใช้งานอยู่ | เปิดใช้งานบัญชี |
| Deactivate | ใช้งานอยู่ | ปิดใช้งานบัญชี |
| Save | ในฟอร์ม | บันทึกการเปลี่ยนแปลง |
| Close | ในฟอร์ม | ปิดฟอร์มโดยไม่บันทึก |

---

## กฎทางธุรกิจ

1. Email ไม่สามารถแก้ไขหลังสร้างบัญชีแล้ว
2. ผู้ใช้ที่ปิดใช้งาน (Deactivated) จะเข้าระบบไม่ได้
3. PIN มือถือใช้เฉพาะกับ Handheld App เท่านั้น
4. สถานะ "Pending" หมายความว่าส่งอีเมลเชิญแล้ว รอผู้ใช้ยืนยันอีเมล

---

## คำถามที่พบบ่อย

**ถาม:** ผู้ใช้ลืมรหัสผ่าน ทำอย่างไร?
**ตอบ:** แก้ไขบัญชีผู้ใช้และตั้งรหัสผ่านใหม่ให้

**ถาม:** PIN มือถือกี่หลัก?
**ตอบ:** สูงสุด 6 หลัก

**ถาม:** เพิ่ม customer_user ต้องระบุอะไรเพิ่ม?
**ตอบ:** ต้องเลือก "ลูกค้า" ที่ผู้ใช้นั้นสังกัด เพื่อให้ระบบแสดงเฉพาะข้อมูลของลูกค้านั้น
