# แดชบอร์ดผู้ดูแลระบบ (Admin Dashboard)

## วัตถุประสงค์
แดชบอร์ดให้ภาพรวมสถานะการดำเนินงานของคลังสินค้า และเข้าถึงงานสำคัญต่างๆ ได้รวดเร็ว ผู้ดูแลระบบจะเห็นข้อมูลครบทุกลูกค้า

## ผู้ใช้งาน
- System Administrator (admin)
- Warehouse Manager
- Warehouse Admin

## สิทธิ์ที่ต้องการ
- **Admin**, **Warehouse Manager**, หรือ **Warehouse Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| หน้าหลัก | `/dashboard` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: KPI Cards (ข้อมูลสรุปด่วน)

| การ์ด | ความหมาย |
|-------|---------|
| จำนวนสินค้าทั้งหมด | รายการสินค้าที่ลงทะเบียนในระบบ |
| จำนวนตำแหน่ง | ช่องจัดเก็บสินค้าทั้งหมดในคลัง |
| การรับสินค้าที่ค้างอยู่ | คำขอฝากที่รอรับสินค้าเข้าคลัง |
| ยอดสินค้าคงเหลือ | สรุปยอดรวมทุกลูกค้า |
| ปริมาณสินค้าทั้งหมด | จำนวนรวม (กล่อง/ชิ้น) ในคลัง |
| รายการเคลื่อนไหว | จำนวนรายการสต็อกที่บันทึกในระบบ |

### ส่วนที่ 2: ขั้นตอนการดำเนินงาน (Workflow)

แสดงขั้นตอนการทำงานหลักในรูปแบบแผนผัง:

```
รับสินค้า (Receiving) → จัดเก็บ (Putaway) → สต็อก (Stock) → หยิบสินค้า (Picking) → ส่งออก (Dispatch)
```

แต่ละขั้นตอนมีตัวเลขแสดงจำนวนงานที่รอดำเนินการ

### ส่วนที่ 3: รายการงานวันนี้ (Today's Task List)

รายการงานที่ต้องดำเนินการวันนี้:
- คำขอฝากสินค้าที่รอรับ
- คำขอเบิกสินค้าที่รออนุมัติ
- งาน Picking ที่ค้างอยู่

### ส่วนที่ 4: การแจ้งเตือนระบบ (System Alerts)

แจ้งเตือนสถานการณ์ที่ต้องสนใจ เช่น:
- สินค้าใกล้หมดอายุ
- พื้นที่คลังเกือบเต็ม

### ส่วนที่ 5: แผนผังคลังสินค้า (Warehouse Layout Map)

แสดงแผนที่คลังสินค้าแบบกราฟิก:
- สีเขียว = ว่าง
- สีส้ม/แดง = ใช้งานมาก

---

## กฎทางธุรกิจ

1. Admin เห็นข้อมูลรวมทุกลูกค้า — ต่างจาก Customer Portal ที่เห็นเฉพาะข้อมูลตนเอง
2. KPI Cards อัปเดตอัตโนมัติ (Realtime หรือ Refresh หน้า)
3. คลิกที่ Card เพื่อเข้าถึงหน้าที่เกี่ยวข้องได้โดยตรง

---

## แนวปฏิบัติที่ดี

- ตรวจสอบ System Alerts ทุกเช้าก่อนเริ่มงาน
- ใช้ Today's Task List เพื่อวางแผนงานประจำวัน
- หากพื้นที่คลังเกิน 80% ให้วางแผนจัดพื้นที่หรือแจ้งลูกค้า
