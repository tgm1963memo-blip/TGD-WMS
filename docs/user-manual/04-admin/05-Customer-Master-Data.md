# ข้อมูลหลักลูกค้า (Customer Master Data)

## วัตถุประสงค์
หน้านี้ให้ผู้ดูแลระบบจัดการข้อมูลลูกค้าในระบบ เพื่อใช้เป็นข้อมูลอ้างอิงสำหรับการรับฝากสินค้า การเบิกสินค้า และการเรียกเก็บค่าบริการ

## ผู้ใช้งาน
- System Administrator (admin)
- Warehouse Manager

## สิทธิ์ที่ต้องการ
- **Admin** หรือ **Warehouse Manager**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Administration | ข้อมูลลูกค้า |
| URL | `/admin/customers` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตารางรายชื่อลูกค้า

| คอลัมน์ | ความหมาย |
|---------|---------|
| รหัสลูกค้า | รหัสเฉพาะของลูกค้า (เช่น C001) |
| ชื่อลูกค้า | ชื่อบริษัทหรือชื่อลูกค้า |
| ผู้ติดต่อ | ชื่อผู้ติดต่อหลัก |
| เบอร์โทรศัพท์ | เบอร์ติดต่อ |
| อีเมล | อีเมลสำหรับแจ้งเตือน |
| สถานะ | ใช้งาน / ปิดใช้งาน |
| การดำเนินการ | ปุ่มแก้ไข |

### ส่วนที่ 2: ฟอร์มสร้าง/แก้ไขลูกค้า

| ฟิลด์ | บังคับ | คำอธิบาย |
|-------|--------|---------|
| รหัสลูกค้า | ใช่ | รหัสเฉพาะ (ไม่ซ้ำ) |
| ชื่อลูกค้า | ใช่ | ชื่อบริษัท/ชื่อลูกค้า |
| ผู้ติดต่อ | ไม่ | ชื่อผู้ติดต่อหลัก |
| เบอร์โทรศัพท์ | ไม่ | เบอร์ติดต่อ |
| อีเมล | ไม่ | อีเมลสำหรับแจ้งเตือนจากระบบ |
| ที่อยู่ | ไม่ | ที่อยู่สำหรับออกใบแจ้งหนี้ |
| หมายเหตุ | ไม่ | ข้อมูลเพิ่มเติม |

## ขั้นตอนการสร้างลูกค้าใหม่

**ขั้นตอนที่ 1:** กด **สร้างลูกค้าใหม่**

**ขั้นตอนที่ 2:** กรอกรหัสลูกค้าและชื่อลูกค้า

**ขั้นตอนที่ 3:** กรอกข้อมูลผู้ติดต่อ

**ขั้นตอนที่ 4:** กด **บันทึก**

---

## ขั้นตอนหลังสร้างลูกค้า

หลังสร้างลูกค้าแล้ว ต้องดำเนินการเพิ่มเติม:

1. **เพิ่มสินค้า (Product Catalog)** — ระบุรายการสินค้าที่ลูกค้านำมาฝาก
2. **กำหนดอัตราค่าบริการ (Service Rates)** — ราคาค่าเก็บ ค่าเข้า-ออก
3. **สร้างบัญชีผู้ใช้** — เพิ่มผู้ใช้ประเภท customer_user และผูกกับลูกค้านี้

---

## กฎทางธุรกิจ

1. รหัสลูกค้าไม่สามารถแก้ไขหลังสร้างแล้ว
2. ลูกค้าที่มีข้อมูลในระบบ (สินค้า, คำขอ) ไม่สามารถลบได้ — ทำได้แค่ปิดใช้งาน
3. อีเมลลูกค้าจะรับการแจ้งเตือนจากระบบ (เมื่อตั้งค่า Email ไว้)

---

## คำถามที่พบบ่อย

**ถาม:** ลูกค้าสองรายมีชื่อเหมือนกัน แยกกันอย่างไร?
**ตอบ:** ใช้รหัสลูกค้า (Customer Code) เป็นตัวแยกหลัก ชื่อสามารถซ้ำกันได้

**ถาม:** ต้องการปิดบัญชีลูกค้าชั่วคราว ทำอย่างไร?
**ตอบ:** เปลี่ยนสถานะเป็น "ปิดใช้งาน" — ลูกค้าจะไม่ปรากฏในรายการตัวเลือกใหม่ แต่ข้อมูลเก่าคงอยู่
