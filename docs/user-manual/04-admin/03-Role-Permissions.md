# การจัดการสิทธิ์และบทบาท (Role Permissions)

## วัตถุประสงค์
หน้านี้ให้ผู้ดูแลระบบสร้างและแก้ไขบทบาทผู้ใช้ และกำหนดสิทธิ์การเข้าถึงแต่ละฟังก์ชันในระบบ

## ผู้ใช้งาน
- System Administrator (admin)

## สิทธิ์ที่ต้องการ
- **Admin** เท่านั้น

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Administration | Role Permissions |
| URL | `/admin/role-permissions` |

---

## คำอธิบายหน้าจอ

หน้านี้มี **3 แท็บ:**

### แท็บที่ 1: บทบาท (Roles)

แสดงการ์ดบทบาททั้งหมด แต่ละการ์ดแสดง:

| ข้อมูล | ความหมาย |
|--------|---------|
| ชื่อบทบาท (Display Name) | ชื่อที่แสดงในระบบ |
| รหัสบทบาท (Role Code) | รหัสเฉพาะ (ตัวพิมพ์เล็ก) |
| คำอธิบาย | หน้าที่ของบทบาทนี้ |
| บทบาทพื้นฐาน (Base Role) | บทบาทที่ใช้อ้างอิงสิทธิ์ |
| จำนวนผู้ใช้ | ผู้ใช้ที่มีบทบาทนี้ |
| ประเภท | ระบบ / กำหนดเอง |

**ปุ่ม:** Create New Role

---

### แท็บที่ 2: Permission Matrix (ตารางสิทธิ์)

ตารางให้ปรับสิทธิ์การเข้าถึงแต่ละฟังก์ชัน:

**แถว (ฟังก์ชัน/เมนู):**
- การดำเนินการหลัก (Main Operation)
- การรับสินค้า (Inbound)
- คลังสินค้า (Inventory)
- การส่งออก (Outbound)
- เครื่องมือถือ / Barcode (Handheld)
- พอร์ทัลลูกค้า (Customer Portal)
- การเงิน / บิล (Billing)
- รายงาน (Reports)
- การดูแลระบบ (System Administration)

**คอลัมน์ (บทบาท):**
admin, warehouse_manager, warehouse_admin, warehouse_staff, accounting, viewer, customer_user

**ตัวบ่งบอกสี:**
- **เขียว** = สิทธิ์ค่าเริ่มต้น
- **น้ำเงิน** = สิทธิ์ที่ปรับเอง
- **admin** = ล็อกไม่ให้แก้ไข

---

### แท็บที่ 3: ผู้ใช้ต่อบทบาท (Users by Role)

แสดงรายชื่อผู้ใช้แยกตามบทบาท:
- รูปโปรไฟล์, ชื่อ, อีเมล, สถานะ (ใช้งาน / ปิดใช้)

---

## ขั้นตอนสร้างบทบาทใหม่

**ขั้นตอนที่ 1:** กด **Create New Role**

**ขั้นตอนที่ 2:** กรอกข้อมูล:
- **Role Code** — รหัสเฉพาะ (ตัวพิมพ์เล็ก ไม่มีช่องว่าง เช่น `warehouse_lead`)
- **Display Name** — ชื่อที่แสดง เช่น "หัวหน้าคลัง"
- **คำอธิบาย** — หน้าที่ของบทบาท
- **Base Role** — บทบาทพื้นฐานที่ใช้อ้างอิงสิทธิ์

**ขั้นตอนที่ 3:** กด **Save**

---

## ขั้นตอนปรับสิทธิ์

**ขั้นตอนที่ 1:** ไปที่แท็บ **Permission Matrix**

**ขั้นตอนที่ 2:** คลิก Checkbox ที่ต้องการเปิด/ปิดสิทธิ์

**ขั้นตอนที่ 3:** กด **Save All Permissions**

---

## ปุ่มทั้งหมด

| ปุ่ม | คำอธิบาย |
|------|---------|
| Create New Role | สร้างบทบาทใหม่ |
| Edit Permissions | แก้ไขสิทธิ์ของบทบาท |
| Save All Permissions | บันทึกการเปลี่ยนแปลงสิทธิ์ |
| Reset | คืนค่าสิทธิ์เดิม |
| Cancel | ยกเลิกการแก้ไข |

---

## กฎทางธุรกิจ

1. **Admin** มีสิทธิ์สูงสุดและล็อกไม่ให้ลดสิทธิ์
2. Role Code ไม่สามารถแก้ไขหลังสร้างแล้ว
3. บทบาทที่มีผู้ใช้อยู่ไม่สามารถลบได้
4. Base Role กำหนดระดับสิทธิ์พื้นฐาน — การปรับ Permission Matrix เป็นการเพิ่มหรือลดจากพื้นฐาน

---

## คำถามที่พบบ่อย

**ถาม:** สีน้ำเงินในตาราง Permission Matrix หมายความว่าอะไร?
**ตอบ:** หมายความว่าสิทธิ์นั้นถูกปรับจากค่าเริ่มต้น สีเขียวคือค่าเริ่มต้นของระบบ

**ถาม:** สร้างบทบาทพิเศษสำหรับแต่ละทีมได้ไหม?
**ตอบ:** ได้ สร้างบทบาทใหม่โดยเลือก Base Role ที่ใกล้เคียงสุด แล้วปรับ Permission Matrix
