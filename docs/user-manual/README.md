# คู่มือผู้ใช้งาน — TGD Cold Storage WMS

**ระบบบริหารจัดการคลังห้องเย็น TG Cold Storage**
**Production URL:** https://tgc-wms.vercel.app

---

## ภาพรวม

คู่มือนี้ครอบคลุมทุกฟังก์ชันในระบบ TGD WMS จัดเรียงตามบทบาทผู้ใช้งาน เหมาะสำหรับการฝึกอบรมพนักงานและใช้อ้างอิงระหว่างปฏิบัติงาน

---

## โครงสร้างบทบาทในระบบ

| บทบาท | ระดับ | หน้าที่หลัก |
|--------|-------|------------|
| admin | สูงสุด | ดูแลระบบทั้งหมด |
| accounting | 40 | บัญชีและการเงิน |
| warehouse_manager | 30 | ผู้จัดการคลัง |
| warehouse_admin | 25 | ธุรการคลัง |
| warehouse_staff | 20 | เจ้าหน้าที่คลัง |
| viewer | 10 | อ่านข้อมูลเท่านั้น |
| customer_user | พิเศษ | พอร์ทัลลูกค้า |

## ลำดับการอบรม (Training Sequence)

### สำหรับเจ้าหน้าที่คลัง (Warehouse Staff)
```
1. [07-settings/01] โปรไฟล์ & เข้าสู่ระบบ        (2 นาที)
2. [02-staff/01]    เข้าสู่ระบบมือถือ             (3 นาที)
3. [02-staff/02]    รับสินค้าด้วยมือถือ           (10 นาที)
4. [02-staff/03]    หยิบสินค้าด้วยมือถือ          (10 นาที)
```

### สำหรับธุรการคลัง (Warehouse Admin)
```
1. [01-admin/01]    แดชบอร์ด                     (5 นาที)
2. [01-admin/02-03] รายการและรายละเอียดรับสินค้า  (13 นาที)
3. [01-admin/06]    ตรวจสอบคำขอฝาก               (8 นาที)
4. [01-admin/04]    ตรวจสอบคำขอเบิก              (10 นาที)
5. [01-admin/05]    ยอดสินค้าคงเหลือ             (5 นาที)
6. [06-reports/02]  รายงานเคลื่อนไหวสินค้า       (5 นาที)
```

### สำหรับลูกค้า (Customer User)
```
1. [03-customer/01] แดชบอร์ด                    (3 นาที)
2. [03-customer/02-04] ฝากสินค้า (สร้าง/รายการ/รายละเอียด) (20 นาที)
3. [03-customer/05] ยอดสินค้าคงเหลือ            (5 นาที)
4. [03-customer/06-08] เบิกสินค้า (สร้าง/รายการ/รายละเอียด) (20 นาที)
```

### สำหรับผู้ดูแลระบบ (System Admin)
```
1. [04-admin/02]    จัดการผู้ใช้                 (10 นาที)
2. [04-admin/03]    สิทธิ์และบทบาท              (10 นาที)
3. [04-admin/04]    พื้นที่คลัง                  (8 นาที)
4. [04-admin/05-07] ข้อมูลลูกค้า/สินค้า/อัตรา   (21 นาที)
5. [04-admin/08-09] นโยบาย/อีเมล                (8 นาที)
```

### สำหรับบัญชี (Accounting)
```
1. [05-billing/01]  รายการน้ำหนักสำหรับบิล       (8 นาที)
2. [05-billing/02-03] ใบแจ้งหนี้ร่าง             (15 นาที)
3. [05-billing/06]  สรุปค่าเก็บรายเดือน         (8 นาที)
4. [05-billing/04-05] ตรวจสอบก่อนส่งบัญชี       (13 นาที)
5. [06-reports/03]  รายงานอายุสินค้า             (8 นาที)
```
