# ตั้งค่าโปรไฟล์ (Profile Settings)

## วัตถุประสงค์
หน้านี้ให้ผู้ใช้ดูข้อมูลบัญชีของตนเอง เช่น อีเมล บทบาท และสถานะการใช้งาน

## ผู้ใช้งาน
- ผู้ใช้ทุกบทบาท

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| เมนูผู้ใช้ (User Menu) | โปรไฟล์ / Profile |
| URL | `/settings/profile` |

---

## คำอธิบายหน้าจอ

### ข้อมูลที่แสดง

| ข้อมูล | ความหมาย |
|--------|---------|
| อีเมล | อีเมลสำหรับเข้าสู่ระบบ |
| บทบาท (Role) | ระดับสิทธิ์ปัจจุบัน |
| สถานะ | ใช้งาน / ปิดใช้งาน |
| ขอบเขตลูกค้า | ระดับการเข้าถึง (ทั้งหมด หรือเฉพาะลูกค้าที่กำหนด) |
| ชื่อที่แสดง (Display Name) | ชื่อที่ปรากฏในระบบ |

### ลิงก์ที่มีให้

- **เปลี่ยนรหัสผ่าน** — ไปยังหน้าเปลี่ยนรหัสผ่าน

---

## กฎทางธุรกิจ

1. ข้อมูลในหน้านี้เป็น **อ่านอย่างเดียว** ไม่สามารถแก้ไขได้เอง
2. หากต้องการแก้ไข Display Name หรือบทบาท ติดต่อ Admin
3. อีเมลไม่สามารถเปลี่ยนได้

---

## คำถามที่พบบ่อย

**ถาม:** ต้องการเปลี่ยนชื่อที่แสดงในระบบ ทำได้เองไหม?
**ตอบ:** ไม่ได้ ต้องให้ Admin แก้ไขในหน้า User Management

**ถาม:** บทบาทของฉันไม่ถูกต้อง ต้องทำอย่างไร?
**ตอบ:** ติดต่อ Admin เพื่อให้แก้ไขบทบาทในระบบ
