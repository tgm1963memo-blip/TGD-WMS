# รายงานอายุการจัดเก็บสินค้า (Storage Aging Report)

## วัตถุประสงค์
รายงานนี้แสดงอายุการจัดเก็บและวันหมดอายุของสินค้าทุก LOT ในคลัง ให้ทราบว่าสินค้าใดใกล้หมดอายุหรือหมดอายุแล้ว เพื่อวางแผนจัดการสินค้าได้ทันเวลา

## ผู้ใช้งาน
- Admin, Warehouse Manager, Warehouse Admin
- Accounting, Viewer
- Customer (เห็นเฉพาะสินค้าของตนเอง)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports | รายงานอายุสินค้า |
| URL | `/reports/storage-aging` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| วันที่เริ่มต้น | วันที่เริ่มคำนวณอายุ |
| วันที่สิ้นสุด | วันที่สิ้นสุดคำนวณ |
| ลูกค้า | กรองตามลูกค้า |
| สินค้า | กรองตามสินค้า |

### ส่วนที่ 2: การ์ดสรุป 5 รายการ

| การ์ด | ความหมาย |
|-------|---------|
| อายุจัดเก็บเฉลี่ย (วัน) | จำนวนวันเฉลี่ยที่สินค้าอยู่ในคลัง |
| อายุสินค้าคงเหลือเฉลี่ย (วัน) | เวลาที่เหลือก่อนหมดอายุโดยเฉลี่ย |
| สินค้าหมดอายุ (ล็อต) | จำนวน LOT ที่เลยวันหมดอายุแล้ว |
| สินค้าใกล้หมดอายุ (ล็อต) | จำนวน LOT ที่จะหมดอายุภายใน 30 วัน |
| ไม่มีวันหมดอายุ (ล็อต) | จำนวน LOT ที่ไม่ได้ระบุวันหมดอายุ |

### ส่วนที่ 3: ตารางแจ้งเตือนสินค้าใกล้หมดอายุ (Expiry Alert)

แสดงเฉพาะสินค้าที่ต้องให้ความสนใจ (หมดอายุ / ใกล้หมดอายุ):

| คอลัมน์ | ความหมาย |
|---------|---------|
| ลูกค้า | ลูกค้าเจ้าของสินค้า |
| สินค้า | ชื่อ/รหัสสินค้า |
| ตำแหน่งจัดเก็บ | ที่อยู่สินค้า |
| ยอดจัดเก็บ | ปริมาณในคลัง |
| หน่วย | UOM |
| วันที่รับเข้า | วันเริ่มเก็บ |
| อายุจัดเก็บ (วัน) | จำนวนวันที่เก็บมา |
| วันหมดอายุ | EXP Date |
| อายุสินค้าคงเหลือ (วัน) | วันที่เหลือ (ลบ = เลยวันแล้ว) |
| สถานะ | GOOD / NEAR_EXPIRY / EXPIRED / NO_EXPIRY_DATE |
| วันคิดค่าฝาก | จำนวนวันที่คิดค่าบริการ |

### ส่วนที่ 4: ตารางสินค้าทั้งหมด (Storage Aging Table)

คอลัมน์เหมือนกับตาราง Expiry Alert แต่แสดงสินค้าทุก LOT

### ส่วนที่ 5: สรุปตามลูกค้าและคลัง (Aging Bucket Summary)

**ตามลูกค้า:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| ลูกค้า | ชื่อลูกค้า |
| จำนวนรายการ | จำนวน LOT |
| ยอดจัดเก็บรวม | ปริมาณรวม |
| อายุจัดเก็บเฉลี่ย | อายุเฉลี่ยทุก LOT |
| วันคิดค่าฝากรวม | รวมวันที่คิดค่าบริการ |
| ใกล้หมดอายุ | จำนวน LOT ใกล้หมด |
| หมดอายุแล้ว | จำนวน LOT เลยกำหนด |

---

## สถานะอายุสินค้า

| สถานะ | ความหมาย | สี |
|------|----------|-----|
| GOOD (ปกติ) | อายุสินค้าเหลือมากกว่า 30 วัน | เขียว |
| NEAR_EXPIRY (ใกล้หมดอายุ) | เหลือ 1-30 วัน | เหลือง |
| EXPIRED (หมดอายุ) | เลยวันหมดอายุแล้ว | แดง |
| NO_EXPIRY_DATE (ไม่มีวันหมดอายุ) | ไม่ได้ระบุวันหมดอายุ | เทา |

## ปุ่มทั้งหมด

| ปุ่ม | คำอธิบาย |
|------|---------|

---

## กฎทางธุรกิจ

1. **NEAR_EXPIRY** = เหลืออายุ ≤ 30 วัน
2. **EXPIRED** = วันหมดอายุผ่านมาแล้ว (อายุสินค้าคงเหลือ < 0)
3. สินค้า EXPIRED ยังคงในคลังจนกว่าลูกค้าจะแจ้งเบิกออก
4. การ์ดสรุปและตารางมาจากข้อมูลชุดเดียวกัน — ตัวเลขสอดคล้องกัน

---

## คำถามที่พบบ่อย

**ถาม:** สินค้า EXPIRED ในคลัง คลังต้องทำอย่างไร?
**ตอบ:** แจ้งลูกค้าทราบ และรอคำขอเบิกสินค้าออก ไม่สามารถทิ้งสินค้าของลูกค้าได้โดยไม่ได้รับอนุญาต

**ถาม:** ทำไมบางล็อตมีสถานะ NO_EXPIRY_DATE?
**ตอบ:** ลูกค้าไม่ได้ระบุวันหมดอายุตอนสร้างคำขอฝาก เช่น สินค้าที่ไม่มีวันหมดอายุตามกฎหมาย
