# รายงานผลการดำเนินงานคลังสินค้า (Warehouse Operation Performance)

## วัตถุประสงค์
รายงานนี้สรุปปริมาณงานและผลการดำเนินงานของคลังสินค้า เช่น จำนวนการรับ-ส่งสินค้า สถานะงานที่ค้างและเสร็จสิ้น เพื่อใช้วางแผนและประเมินประสิทธิภาพ

## ผู้ใช้งาน
- Admin, Warehouse Manager
- Accounting (สำหรับประกอบการออกบิล)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports | ผลการดำเนินงานคลัง |
| URL | `/reports/warehouse-performance` |

## กฎทางธุรกิจ

1. รายงานนี้เป็น **อ่านอย่างเดียว** ใช้เพื่อวิเคราะห์และวางแผนเท่านั้น
2. "รายการค่าบริการ" หมายถึงงานที่อาจมีค่าบริการเพิ่มเติม เช่น ค่ายก ค่าแพ็ค ค่าติดฉลาก
3. ข้อมูลอัปเดตตามรายการจริงในระบบ

## คำถามที่พบบ่อย

**ถาม:** ใช้รายงานนี้เพื่ออะไรได้บ้าง?
**ตอบ:** (1) วางแผนกำลังคนรายวัน (2) ตรวจสอบงานค้างที่ต้องเร่ง (3) ประกอบการออกบิลค่าบริการพิเศษ

**ถาม:** "จำนวนรายการค่าบริการ" ใช้ประโยชน์อย่างไร?
**ตอบ:** ใช้สำหรับฝ่ายบัญชีตรวจสอบว่ามีค่าบริการดำเนินงานพิเศษ (ยก แพ็ค ติดฉลาก) ที่ต้องเรียกเก็บหรือไม่
