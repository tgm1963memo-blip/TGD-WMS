# รายงานยอดคงคลังลูกค้า (Customer Storage Balance Report)

## วัตถุประสงค์
รายงานนี้แสดงยอดสินค้าคงเหลือในปัจจุบันของทุกลูกค้า แยกตาม LOT หมายเลขพาเลท คลัง และตำแหน่ง ให้รู้ว่าสินค้าแต่ละล็อตอยู่ที่ไหนและมีเท่าไหร่

## ผู้ใช้งาน
- Admin, Warehouse Manager, Warehouse Admin
- Accounting, Viewer

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports | ยอดคงคลังลูกค้า |
| URL | `/reports/customer-storage-balance` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: การ์ดสรุป 8 รายการ

| การ์ด | ความหมาย |
|-------|---------|
| จำนวนลูกค้า | ลูกค้าที่มีสินค้าในคลัง |
| จำนวน SKU / สินค้า | รายการสินค้าทั้งหมด |
| จำนวนล็อต | จำนวน LOT ทั้งหมด |
| จำนวนพาเลท | จำนวนพาเลทที่ใช้ |
| ยอดสินค้ารวม | ปริมาณรวมทั้งคลัง |
| ยอดพร้อมใช้ | ยอดที่ยังไม่ถูกจองเบิก |
| ยอดที่จอง | ยอดที่อยู่ระหว่างดำเนินการเบิก |
| ปริมาณ/น้ำหนักที่คิดได้ | ประมาณการสำหรับค่าเก็บรายเดือน |

### ส่วนที่ 2: ตารางรายละเอียด (Customer Storage Balance Table)

| คอลัมน์ | ความหมาย |
|---------|---------|
| ลูกค้า | เจ้าของสินค้า |
| สินค้า | รหัสและชื่อสินค้า |
| LOT No | หมายเลขล็อต |
| พาเลท | หมายเลขพาเลท |
| คลัง | คลังที่เก็บ |
| ห้อง / โซน | ห้องและโซนที่เก็บ |
| ตำแหน่ง | รหัสตำแหน่งเฉพาะ (เช่น H1-L-01-02) |
| สภาพ | สภาพสินค้า |
| ยอดสินค้า | จำนวนทั้งหมด |
| ยอดที่จอง | จำนวนที่อยู่ระหว่างเบิก |
| ยอดพร้อมใช้ | ยอดที่ยังเบิกได้ |
| หน่วย | UOM |
| วันที่รับเข้า | วันที่เริ่มเก็บสินค้า |
| วันที่เคลื่อนไหวล่าสุด | วันที่มีการเคลื่อนไหวล่าสุด |
| หมายเหตุบิล | ข้อมูลสำหรับฝ่ายบัญชี |

### ส่วนที่ 3: ตารางสรุปตามมุมมองต่างๆ

**สรุปตามลูกค้า:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| ลูกค้า | ชื่อลูกค้า |
| ยอดสินค้า | รวมปริมาณ |
| ยอดที่จอง | รวมที่อยู่ระหว่างเบิก |
| ยอดพร้อมใช้ | รวมที่เบิกได้ |
| จำนวนรายการ | จำนวน LOT |

**สรุปตามคลัง / สรุปตาม LOT-พาเลท:**
- คอลัมน์เหมือนกับสรุปตามลูกค้า แยกกลุ่มต่างกัน

## กฎทางธุรกิจ

1. **ยอดพร้อมใช้** = ยอดสินค้า - ยอดที่จอง
2. **ยอดที่จอง** = สินค้าที่อยู่ในคำขอเบิกที่กำลังดำเนินการ
3. รายงานนี้เป็น **อ่านอย่างเดียว** ไม่แก้ไขข้อมูลได้

## คำถามที่พบบ่อย

**ถาม:** ยอดพร้อมใช้กับยอดสินค้าต่างกัน เป็นเพราะอะไร?
**ตอบ:** มีคำขอเบิกที่อยู่ระหว่างดำเนินการ (WAREHOUSE_PICKING) ทำให้สินค้าบางส่วนถูกจอง

**ถาม:** ตำแหน่ง H1-L-01-02 หมายความว่าอะไร?
**ตอบ:** ห้อง H1, ฝั่งซ้าย (L=Left), แถวที่ 01, ชั้นที่ 02
