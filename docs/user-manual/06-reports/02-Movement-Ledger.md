# รายงานการเคลื่อนไหวสินค้า (Movement Ledger Report)

## วัตถุประสงค์
รายงานนี้แสดงประวัติการเคลื่อนไหวสินค้าทุกรายการ ทั้งการรับเข้าและส่งออก ให้ตรวจสอบความถูกต้องและใช้ประกอบการออกใบแจ้งหนี้

## ผู้ใช้งาน
- Admin, Warehouse Manager, Warehouse Admin, Warehouse Staff
- Accounting, Viewer

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports | รายการเคลื่อนไหวสินค้า |
| URL | `/reports/movement-ledger` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| วันที่เริ่มต้น / สิ้นสุด | ช่วงวันที่ของรายการ |
| ลูกค้า | กรองตามลูกค้า |
| สินค้า | เลือกสินค้าได้หลายรายการ |
| ตำแหน่งจัดเก็บ | เลือกตำแหน่งได้หลายแห่ง |
| คลังสินค้า | รหัสคลัง |
| ประเภทอ้างอิง | ประเภทเอกสารต้นทาง |

### ส่วนที่ 2: ตารางรายการเคลื่อนไหว

| คอลัมน์ | ความหมาย |
|---------|---------|
| วันที่ | วันที่เกิดรายการ |
| ประเภท | Badge ประเภทการเคลื่อนไหว |
| สินค้า | รหัส — ชื่อสินค้า |
| ลูกค้า | ลูกค้าที่เกี่ยวข้อง |
| จำนวน | (+) รับเข้า / (-) ส่งออก |
| อ้างอิง | เลขที่เอกสารต้นทาง |
| วันที่สร้าง | วันที่บันทึกในระบบ |

**คลิกขยายแถวเพื่อดูรายละเอียด:**

| รายละเอียด | ความหมาย |
|-----------|---------|
| LOT No | หมายเลขล็อต |
| ตำแหน่งต้นทาง | ตำแหน่งที่นำสินค้าออก |
| ตำแหน่งปลายทาง | ตำแหน่งที่วางสินค้า |
| หน่วย (UOM) | หน่วยนับ |
| ประเภทอ้างอิง | ประเภทเอกสาร |
| เลขที่อ้างอิง | รหัสเอกสาร |
| เอกสารอ้างอิง | ลิงก์ไปยังเอกสารต้นทาง |

---

## ปุ่มทั้งหมด

| ปุ่ม | คำอธิบาย |
|------|---------|
| ค้นหา | กรองรายการตามเงื่อนไข |
| รีเซ็ต | ล้างตัวกรองทั้งหมด |
| Export | ดาวน์โหลดรายการเป็น CSV |
| รายงานรับ-ส่งสินค้า | พิมพ์รายงาน Entry-Delivery แบบเป็นทางการ |

---

## กฎทางธุรกิจ

1. รายงานนี้เป็น **อ่านอย่างเดียว** ไม่สามารถแก้ไขข้อมูลได้
2. จำนวน (+) = รับเข้าคลัง; (-) = ส่งออกจากคลัง
3. คลิกที่เลขที่อ้างอิงเพื่อเชื่อมไปยังเอกสารต้นทาง

---

## คำถามที่พบบ่อย

**ถาม:** ต้องการดูเฉพาะรายการรับเข้า ทำได้ไหม?
**ตอบ:** กรองด้วย "ประเภทอ้างอิง" เลือกเฉพาะประเภทรับเข้า (INBOUND)

**ถาม:** รายงาน Entry-Delivery แตกต่างจากตารางหลักอย่างไร?
**ตอบ:** เป็นรูปแบบเอกสารทางการสำหรับพิมพ์ แสดงข้อมูลลูกค้าและสรุปยอดใน format มาตรฐาน
