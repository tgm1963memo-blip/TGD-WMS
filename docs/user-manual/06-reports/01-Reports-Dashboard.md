# หน้าหลักรายงาน (Reports Dashboard)

## วัตถุประสงค์
หน้านี้เป็นศูนย์กลางสำหรับเข้าถึงรายงานทั้งหมดในระบบ แสดงรายงานที่ผู้ใช้มีสิทธิ์เข้าถึง

## ผู้ใช้งาน
- Admin, Warehouse Manager, Warehouse Admin
- Accounting (เห็นรายงานเพิ่มเติมด้านบัญชี)
- Viewer (อ่านอย่างเดียว)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports | `/reports` |

---

## รายงานทั้งหมดในระบบ

| รายงาน | วัตถุประสงค์ | สิทธิ์ |
|---------|------------|--------|
| รายการเคลื่อนไหวสินค้า (Movement Ledger) | ติดตามการเข้า-ออกสินค้าทุกรายการ | ทุกบทบาท |
| ยอดคงคลังลูกค้า (Customer Storage Balance) | ดูยอดสินค้าคงเหลือแยกตาม LOT/ตำแหน่ง | ทุกบทบาท |
| รายงานอายุสินค้า (Storage Aging) | ตรวจสอบอายุสินค้าและวันหมดอายุ | ทุกบทบาท |
| ผลการดำเนินงานคลัง (Warehouse Operation Performance) | สรุปปริมาณงานและประสิทธิภาพ | ทุกบทบาท |
| สรุปค่าเก็บรายเดือน (Monthly Billing Summary) | สรุปค่าบริการรายเดือน | Accounting, Admin |
| รายการน้ำหนักสำหรับบิล (Billing Movement Weight) | เลือกรายการเพื่อออกใบแจ้งหนี้ | Accounting, Admin |
| ดูตัวอย่างข้อมูลบัญชี (Accounting Staging Preview) | ตรวจสอบก่อนส่งระบบบัญชี | Accounting เท่านั้น |
| ตรวจสอบก่อนส่งบัญชี (Accounting Handoff Review) | ตรวจสอบขั้นสุดท้าย | Accounting เท่านั้น |

---

## หมายเหตุ

- รายงานทั้งหมดเป็น **อ่านอย่างเดียว** (Read-Only)
- ทุกรายงานรองรับการ **Export** (CSV หรือ Excel)
- รายงานที่ต้องการสิทธิ์พิเศษจะไม่แสดงสำหรับผู้ใช้ที่ไม่มีสิทธิ์
