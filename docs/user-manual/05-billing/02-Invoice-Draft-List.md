# รายการใบแจ้งหนี้ร่าง (Invoice Draft List)

## วัตถุประสงค์
หน้านี้แสดงรายการใบแจ้งหนี้ร่างทั้งหมด พร้อมสถานะและข้อมูลสรุป ให้เจ้าหน้าที่บัญชีติดตามและจัดการใบแจ้งหนี้

## ผู้ใช้งาน
- Accounting
- Admin

## สิทธิ์ที่ต้องการ
- **Accounting** หรือ **Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Billing | ใบแจ้งหนี้ร่าง |
| URL | `/billing/invoice-drafts` |

## ขั้นตอนการดูรายละเอียด

**ขั้นตอนที่ 1:** กด **View** ที่รายการที่ต้องการ

**ขั้นตอนที่ 2:** ระบบแสดง Modal รายละเอียด ประกอบด้วย:
- ข้อมูลหัวบิล (เลขที่, ลูกค้า, สถานะ, งวด, ยอดรวม)
- ตารางรายการสินค้า (เอกสารต้นทาง, สินค้า, ประเภท, วันที่, จำนวน, น้ำหนัก)

> **หมายเหตุ:** ร่างใบแจ้งหนี้ตามช่วงเวลาจะมีรายการค่านำออก (HANDLING_OUT) แยกต่อรายการสินค้าในคำขอเบิกแต่ละบรรทัด โดยใช้วันที่ส่งออกสินค้า (dispatch) เป็นวันที่ของรายการ

**ขั้นตอนที่ 3:** กด **Print Invoice** เพื่อพิมพ์

## Export Excel ตามแบบลูกค้า

ใช้สร้างไฟล์ Excel ใบคำนวณค่าบริการในรูปแบบที่ส่งให้ลูกค้า (หัวรายงาน สูตร สี และ sheet เหมือนไฟล์ที่ฝ่ายบัญชีเคยทำด้วยมือ)

**กดได้ 2 จุด:**
- ใน Modal **สร้างบิลค่าฝาก/ค่าบริการตามช่วงเวลา** แท็บ "ตามช่วงเวลาที่ระบุเอง" หลังกด **ดูตัวอย่างก่อนสร้าง**
- ใน Modal **View** ของใบแจ้งหนี้ร่างที่สร้างแล้ว

**ขั้นตอน:**
1. เลือก **รูปแบบ Excel** — แบบหัวตารางน้ำเงินเข้ม (OVO / THAIMAX) หรือแบบฟ้าอ่อน (TGM) ระบบเลือกให้ตามลูกค้าไว้ก่อน เปลี่ยนได้
2. กด **Export Excel ตามแบบลูกค้า** — ได้ไฟล์ค่าบริการของลูกค้า / ช่วงเวลา / ประเภทจัดเก็บ / กลุ่มสินค้าที่เลือก
3. กด **Export รายงาน OT** — ได้ไฟล์ค่าล่วงเวลาแยกต่างหาก รวมทุกกลุ่มสินค้าของลูกค้าในช่วงเวลานั้น

**Sheet ในไฟล์ค่าบริการ** (สร้างเฉพาะ sheet ที่มีรายการ):

| Sheet | เนื้อหา |
|-------|--------|
| ค่าบริการรับฝาก (หรือ Frozen / Chilled เมื่อมีมากกว่า 1 ห้อง) | 1 แถวต่อรหัสติดตาม × ก้อนที่จ่ายออกในงวด และยอดคงเหลือ ณ วัน cut-off พร้อมกล่อง "สรุปค่าบริการรวม" |
| ค่าบริการจัดการแรกเข้า | เฉพาะยอดรับเข้าใหม่ในงวด |
| ค่าบริการแช่เยือกแข็ง / Slow Freeze / ใบอนุญาต ร.3 | ตามรายการที่ระบบคิดในงวด |
| ค่าบริการอื่น ๆ | ค่านำออก ค่าละลาย ส่วนแบ่งค่า OT บริการเสริมอื่น และยอดปรับตามเงื่อนไขสัญญา |
| Movement Ledger / Stock Report | ความเคลื่อนไหวในงวด และยอดคงเหลือ ณ วันสิ้นงวด |

> **หมายเหตุ:**
> - ตัวเลขคำนวณใหม่จากข้อมูลและอัตราปัจจุบันทุกครั้งที่กด export ถ้ายอดไม่ตรงกับยอดที่บันทึกในร่าง ระบบจะแจ้งตัวเลขทั้งสองฝั่งหลังดาวน์โหลด
> - ช่องค่าบริการเป็นสูตร Excel จริง ซึ่งปัดเศษต่อแถว จึงอาจต่างจากยอดของระบบ (ปัดต่อรอบ) ได้ระดับสตางค์ ระบบจะแจ้งส่วนต่างให้เห็นเช่นกัน
> - ร่างที่สร้างจากแท็บ "งวดอัตโนมัติต่อล็อต" ใช้งวดต่อ lot ไม่ตรงกับรูปแบบ cut-off เดียวของไฟล์นี้ ยอดจึงจะไม่ตรงกับร่าง

---

## กฎทางธุรกิจ

1. ใบแจ้งหนี้ร่างสร้างจากหน้านี้ (ใบแจ้งหนี้ร่าง) ด้วยปุ่ม **+ สร้างบิลค่าฝาก/ค่าบริการตามช่วงเวลา** เท่านั้น
2. ไม่สามารถแก้ไขรายการในร่างโดยตรง ต้องยกเลิกและสร้างใหม่
3. CANCELLED เป็นสถานะสุดท้าย ไม่สามารถเปิดใหม่ได้

## คำถามที่พบบ่อย

**ถาม:** ต้องการดูรายละเอียดรายการที่อยู่ในบิล ทำได้อย่างไร?
**ตอบ:** กด View → ดูที่ตารางรายการด้านล่าง Modal

**ถาม:** ใบแจ้งหนี้ถูกยกเลิกแล้ว จะสร้างใหม่อย่างไร?
**ตอบ:** ที่หน้าใบแจ้งหนี้ร่าง กด **+ สร้างบิลค่าฝาก/ค่าบริการตามช่วงเวลา** เลือกลูกค้าและช่วงเวลา แล้วสร้างร่างใหม่
