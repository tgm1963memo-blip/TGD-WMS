# รายการใบแจ้งหนี้ร่าง (Invoice Draft List)

## วัตถุประสงค์
หน้านี้แสดงรายการใบแจ้งหนี้ร่างทั้งหมด พร้อมสถานะและข้อมูลสรุป ให้เจ้าหน้าที่บัญชีติดตามและจัดการใบแจ้งหนี้

## ผู้ใช้งาน
- Accounting
- Admin

## สิทธิ์ที่ต้องการ
- **Accounting** หรือ **Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Billing | ใบแจ้งหนี้ร่าง |
| URL | `/billing/invoice-drafts` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| เลขที่ร่าง | ค้นหาด้วยเลขที่ |
| สถานะ | กรองตามสถานะ |
| ลูกค้า | กรองตามลูกค้า |
| วันที่เริ่มต้น / สิ้นสุด | ช่วงวันที่ |

### ส่วนที่ 2: ตารางรายการ

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่ร่าง | รหัสเฉพาะของใบแจ้งหนี้ร่าง |
| ลูกค้า | ลูกค้าที่ออกบิล |
| สถานะ | Badge สีตามสถานะ |
| งวดเริ่มต้น | วันเริ่มรอบบิล |
| งวดสิ้นสุด | วันสิ้นรอบบิล |
| จำนวนรวม | รวมจำนวนสินค้า |
| น้ำหนักรวม | น้ำหนักที่คิดได้ |
| ยอดรวม | มูลค่ารวมใบแจ้งหนี้ |
| วันที่สร้าง | วันที่ออกร่าง |
| การดำเนินการ | ปุ่ม View |

---

## สถานะใบแจ้งหนี้ร่าง

| สถานะ | ความหมาย | สี |
|------|----------|-----|
| DRAFT | ร่างเริ่มต้น | เทา |
| READY_TO_REVIEW | รอตรวจสอบ | เหลือง |
| APPROVED | อนุมัติแล้ว | เขียว |
| EXPORTED_TO_BPLUS | ส่งออกไประบบบัญชีแล้ว | เขียวเข้ม |
| BILLED | เรียกเก็บเงินแล้ว | เขียวเข้ม |
| CANCELLED | ยกเลิก | แดง |
| ON_HOLD | พักไว้ก่อน | เหลืองเข้ม |

---

## ขั้นตอนการดูรายละเอียด

**ขั้นตอนที่ 1:** กด **View** ที่รายการที่ต้องการ

**ขั้นตอนที่ 2:** ระบบแสดง Modal รายละเอียด ประกอบด้วย:
- ข้อมูลหัวบิล (เลขที่, ลูกค้า, สถานะ, งวด, ยอดรวม)
- ตารางรายการสินค้า (เอกสารต้นทาง, สินค้า, ประเภท, วันที่, จำนวน, น้ำหนัก)

**ขั้นตอนที่ 3:** กด **Print Invoice** เพื่อพิมพ์

---

## กฎทางธุรกิจ

1. ใบแจ้งหนี้ร่างสร้างจากหน้า Billing Movement Weight เท่านั้น
2. ไม่สามารถแก้ไขรายการในร่างโดยตรง ต้องยกเลิกและสร้างใหม่
3. CANCELLED เป็นสถานะสุดท้าย ไม่สามารถเปิดใหม่ได้

---

## คำถามที่พบบ่อย

**ถาม:** ต้องการดูรายละเอียดรายการที่อยู่ในบิล ทำได้อย่างไร?
**ตอบ:** กด View → ดูที่ตารางรายการด้านล่าง Modal

**ถาม:** ใบแจ้งหนี้ถูกยกเลิกแล้ว จะสร้างใหม่อย่างไร?
**ตอบ:** ไปที่หน้า Billing Movement Weight เลือกรายการใหม่และสร้างร่างใหม่
