# ตรวจสอบก่อนส่งข้อมูลบัญชี (Accounting Handoff Review)

## วัตถุประสงค์
หน้านี้ให้เจ้าหน้าที่บัญชีตรวจสอบข้อมูลค่าบริการขั้นสุดท้ายก่อนส่งไประบบบัญชีภายนอก และบันทึกหมายเหตุการตรวจสอบ

## ผู้ใช้งาน
- Accounting
- Admin

## สิทธิ์ที่ต้องการ
- **Accounting** หรือ **Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Billing / Reports | Accounting Handoff Review |
| URL | `/reports/accounting-handoff` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: สรุปการตรวจสอบ (Review Summary)
แสดงสรุปจำนวนรายการและสถานะโดยรวม

### ส่วนที่ 2: แผงปัญหา (Issue Panel)
จัดกลุ่มปัญหาที่พบ เช่น:
- รายการที่ขาดข้อมูล
- รายการที่มีค่าผิดปกติ
- รายการที่ต้องการการตรวจสอบพิเศษ

### ส่วนที่ 3: ตารางตรวจสอบร่าง (Review Draft Table)

| คอลัมน์ | ความหมาย |
|---------|---------|
| Row ID | รหัสแถว |
| ลูกค้า | รหัสลูกค้า |
| ยอดเงิน | มูลค่าค่าบริการ |
| หมายเหตุตรวจสอบ | ช่องให้กรอกบันทึกต่อรายการ |

---

## ขั้นตอนการใช้งาน

**ขั้นตอนที่ 1:** ตรวจสอบ Issue Panel ว่ามีปัญหาหรือไม่

**ขั้นตอนที่ 2:** อ่านรายการในตาราง Review Draft Table

**ขั้นตอนที่ 3:** กรอก **หมายเหตุตรวจสอบ** ต่อแถวที่ต้องการบันทึก

**ขั้นตอนที่ 4:** หากข้อมูลถูกต้องครบถ้วน ดำเนินการส่งออกตามขั้นตอนบัญชีภายนอก

---

## กฎทางธุรกิจ

1. หมายเหตุที่กรอกในหน้านี้ **ไม่บันทึกถาวร** — ใช้เพื่อตรวจสอบเท่านั้น
2. ไม่มีปุ่มส่งออกข้อมูลโดยตรงจากหน้านี้ — การส่งออกจริงดำเนินการผ่านระบบบัญชีภายนอก
3. ต้องแก้ไขปัญหาทั้งหมดใน Issue Panel ก่อนส่งออก

---

## คำถามที่พบบ่อย

**ถาม:** หมายเหตุที่กรอกในหน้านี้จะเก็บไว้ที่ไหน?
**ตอบ:** หมายเหตุอยู่ในหน้าจอชั่วคราวเท่านั้น รีเฟรชหน้าจะหายไป บันทึกสำคัญควรเก็บในระบบอื่น
