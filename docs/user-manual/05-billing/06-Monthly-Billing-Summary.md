# สรุปค่าเก็บรักษารายเดือน (Monthly Billing Summary)

## วัตถุประสงค์
หน้านี้แสดงสรุปค่าบริการเก็บรักษาสินค้ารายเดือนแยกตามลูกค้า เพื่อใช้ตรวจสอบและเตรียมข้อมูลสำหรับออกใบแจ้งหนี้

## ผู้ใช้งาน
- Accounting
- Admin
- Warehouse Manager

## สิทธิ์ที่ต้องการ
- **Accounting**, **Admin**, หรือ **Warehouse Manager**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Reports / Billing | สรุปค่าเก็บรักษารายเดือน |
| URL | `/reports/monthly-billing` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| เดือน | เดือนที่ต้องการ (1-12) |
| ปี | ปีที่ต้องการ (ตั้งแต่ปี 2020) |
| ลูกค้า | รหัสลูกค้า (ถ้าต้องการเฉพาะราย) |
| คลังสินค้า | รหัสคลัง |

### ส่วนที่ 2: การ์ดสรุปภาพรวม

| การ์ด | ความหมาย |
|-------|---------|
| ลูกค้าทั้งหมด | จำนวนลูกค้าที่มีการเคลื่อนไหว |
| จำนวนรับเข้า | รวมปริมาณที่รับเข้าคลัง |
| จำนวนส่งออก | รวมปริมาณที่ส่งออก |
| คงเหลือ | ปริมาณสินค้าคงเหลือในคลัง |
| น้ำหนัก/ปริมาณที่คิดได้ | ปริมาณสำหรับคำนวณค่าบริการ |
| จำนวนรายการค่าบริการ | จำนวนรายการที่มีค่าดำเนินงาน |
| ขาดอัตราค่าบริการ | รายการที่ยังไม่มีอัตราที่กำหนด |
| ขาดน้ำหนัก | รายการที่ขาดข้อมูลน้ำหนัก |
| ต้องตรวจสอบบัญชี | รายการที่ต้องการความสนใจพิเศษ |

### ส่วนที่ 3: ตารางสรุปรายลูกค้า

| คอลัมน์ | ความหมาย |
|---------|---------|
| งวดบิล | เดือน-ปีที่คิดค่าบริการ |
| ลูกค้า | ชื่อ/รหัสลูกค้า |
| คลัง | คลังที่เก็บ |
| รับเข้า | จำนวนรับเข้า |
| ส่งออก | จำนวนส่งออก |
| คงเหลือ | คงเหลือ |
| เฉลี่ยที่เก็บ | จำนวนเฉลี่ยระหว่างเดือน |
| น้ำหนักที่คิดได้ | น้ำหนักสำหรับค่าเก็บ |
| อัตราค่าเก็บ | ราคาต่อหน่วย |
| ประมาณการค่าบริการ | ค่าบริการที่คำนวณได้ |
| ยอดรวมประมาณ | ยอดรวมค่าบริการ |
| สถานะตรวจสอบ | READY_FOR_REVIEW / ต้องแก้ไข |
| หมายเหตุบัญชี | บันทึกเพิ่มเติม |

### ส่วนที่ 4: แผงแจ้งเตือนข้อมูลไม่สมบูรณ์
แสดงรายการที่ต้องแก้ไขก่อนออกใบแจ้งหนี้จริง

---

## ขั้นตอนการใช้งาน

**ขั้นตอนที่ 1:** เลือก **เดือน** และ **ปี** ที่ต้องการ

**ขั้นตอนที่ 2:** เลือก **ลูกค้า** (ถ้าต้องการดูเฉพาะราย)

**ขั้นตอนที่ 3:** กด **ค้นหา**

**ขั้นตอนที่ 4:** ตรวจสอบการ์ดสรุป — หากมีรายการสีเหลือง/แดง ต้องแก้ไขก่อน

**ขั้นตอนที่ 5:** ตรวจสอบตารางรายลูกค้าและยอดรวมประมาณ

**ขั้นตอนที่ 6:** ใช้ข้อมูลนี้อ้างอิงสำหรับสร้างใบแจ้งหนี้จากหน้า Billing Movement Weight

---

## กฎทางธุรกิจ

1. หน้านี้เป็น **ตัวอย่างเพื่อตรวจสอบ** — ยอดรวมเป็น **ประมาณการ** ยังไม่ใช่ยอดบิลจริง
2. ต้องแก้ไขรายการสีแดง (ขาดอัตรา/น้ำหนัก) ก่อนออกบิลจริง
3. ยอดบิลจริงออกจากหน้า Billing Movement Weight → Invoice Draft

---

## คำถามที่พบบ่อย

**ถาม:** ยอดในหน้านี้ต่างจากยอดในใบแจ้งหนี้จริง เป็นไปได้ไหม?
**ตอบ:** ได้ — หน้านี้เป็นการประมาณการ ยอดจริงขึ้นอยู่กับรายการที่เลือกในขั้นตอนสร้างใบแจ้งหนี้

**ถาม:** รายการขาดอัตราค่าบริการ ต้องทำอย่างไร?
**ตอบ:** ไปที่ Administration → อัตราค่าบริการ แล้วกำหนดอัตราให้ลูกค้าและสินค้านั้น
