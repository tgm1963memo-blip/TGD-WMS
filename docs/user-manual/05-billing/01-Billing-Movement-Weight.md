# รายการเคลื่อนไหวน้ำหนักเพื่อเรียกเก็บ (Billing Movement Weight)

## วัตถุประสงค์
หน้านี้แสดงรายการเคลื่อนไหวสินค้าทั้งหมดที่พร้อมนำไปออกใบแจ้งหนี้ ให้เจ้าหน้าที่บัญชีเลือกรายการและสร้างใบแจ้งหนี้ร่าง

## ผู้ใช้งาน
- Accounting
- Admin

## สิทธิ์ที่ต้องการ
- **Accounting** หรือ **Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Billing | รายการเคลื่อนไหวน้ำหนัก |
| URL | `/billing/movement-weight` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง (Filter)

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| วันที่เริ่มต้น / สิ้นสุด | ช่วงวันที่ของรายการเคลื่อนไหว |
| ลูกค้า | กรองตามลูกค้า |
| สินค้า | กรองตามสินค้า |
| ประเภทเคลื่อนไหว | ประเภทการเข้า-ออก |
| สถานะการเรียกเก็บ | READY_FOR_PREVIEW / NEEDS_WEIGHT_REVIEW / EXCLUDED |
| สามารถเรียกเก็บได้ | ทั้งหมด / เรียกเก็บได้ / ยกเว้น |

### ส่วนที่ 2: ตารางรายการ

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลือก (Checkbox) | เลือกรายการสำหรับสร้างใบแจ้งหนี้ |
| ชื่อลูกค้า | ลูกค้าที่เกี่ยวข้อง |
| ประเภทเอกสาร | ประเภทการเคลื่อนไหว |
| จำนวน | ปริมาณ |
| น้ำหนักที่คิดได้ | น้ำหนักสำหรับคำนวณค่าบริการ |
| สถานะ | Badge สีตามสถานะ |

**ขยายแถวเพื่อดูรายละเอียดเพิ่มเติม:**

| รายละเอียด | ความหมาย |
|-----------|---------|
| วันที่เคลื่อนไหว | วันที่รับ/ส่งสินค้า |
| รหัสสินค้า / ชื่อสินค้า | สินค้าที่เกี่ยวข้อง |
| LOT No / Pallet No | หมายเลขล็อต และพาเลท |
| น้ำหนักสุทธิ / น้ำหนักรวม | น้ำหนักจริง |
| น้ำหนักที่คิดได้ | น้ำหนักสำหรับเรียกเก็บ |
| ประเภทบริการเรียกเก็บ | STORAGE / HANDLING_IN / HANDLING_OUT |
| เลขที่เอกสารต้นทาง | อ้างอิงเอกสาร |

---

## สถานะการเรียกเก็บ

| สถานะ | ความหมาย | เลือกได้? |
|------|----------|---------|
| READY_FOR_PREVIEW | พร้อมนำไปออกบิล | ใช่ |
| NEEDS_WEIGHT_REVIEW | น้ำหนักต้องตรวจสอบก่อน | ไม่ |
| EXCLUDED | ยกเว้นจากการเรียกเก็บ | ไม่ |

---

## ขั้นตอนการสร้างใบแจ้งหนี้ร่าง

**ขั้นตอนที่ 1:** ตั้งค่าตัวกรองตามช่วงเวลาและลูกค้าที่ต้องการ

**ขั้นตอนที่ 2:** กด **ค้นหา**

**ขั้นตอนที่ 3:** เลือก Checkbox ที่รายการที่ต้องการ (เฉพาะสถานะ READY_FOR_PREVIEW)

**ขั้นตอนที่ 4:** ตรวจสอบ "จำนวนรายการที่เลือก" ด้านบนตาราง

**ขั้นตอนที่ 5:** กด **Create Draft**

**ขั้นตอนที่ 6:** ระบบสร้างใบแจ้งหนี้ร่างและแสดงลิงก์ไปยังหน้ารายละเอียด

---

## ปุ่มทั้งหมด

| ปุ่ม | คำอธิบาย |
|------|---------|
| ค้นหา | กรองรายการตามเงื่อนไข |
| รีเซ็ต | ล้างตัวกรองทั้งหมด |
| Create Draft | สร้างใบแจ้งหนี้ร่างจากรายการที่เลือก |
| Export CSV | ดาวน์โหลดรายการทั้งหมดเป็น CSV |

---

## กฎทางธุรกิจ

1. เลือกได้เฉพาะรายการสถานะ **READY_FOR_PREVIEW** เท่านั้น
2. รายการ **NEEDS_WEIGHT_REVIEW** ต้องแก้ไขน้ำหนักก่อนนำไปออกบิล
3. ปุ่ม Create Draft จะปิดใช้งานถ้าไม่มีรายการที่เลือก

---

## คำถามที่พบบ่อย

**ถาม:** รายการสถานะ NEEDS_WEIGHT_REVIEW แก้ไขได้จากที่ไหน?
**ตอบ:** ติดต่อเจ้าหน้าที่คลังเพื่อแก้ไขน้ำหนักในระบบก่อน

**ถาม:** Export CSV ได้ข้อมูลอะไรบ้าง?
**ตอบ:** ได้รายการทั้งหมดที่ตรงกับตัวกรอง รวมถึงรายละเอียดน้ำหนักและสถานะ
