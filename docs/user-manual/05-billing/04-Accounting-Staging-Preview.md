# ดูตัวอย่างข้อมูลบัญชี (Accounting Staging Preview)

## วัตถุประสงค์
หน้านี้แสดงตัวอย่างข้อมูลค่าบริการที่จะส่งไประบบบัญชีภายนอก ให้เจ้าหน้าที่บัญชีตรวจสอบความถูกต้องก่อนส่งออก

## ผู้ใช้งาน
- Accounting
- Admin

## สิทธิ์ที่ต้องการ
- **Accounting** หรือ **Admin**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Billing / Reports | Accounting Staging Preview |
| URL | `/reports/accounting-staging` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| เดือน | เดือนที่ต้องการตรวจสอบ (1-12) |
| ปี | ปีที่ต้องการ |
| ลูกค้า | รหัสลูกค้า (ถ้าต้องการเฉพาะราย) |
| คลังสินค้า | รหัสคลัง |

### ส่วนที่ 2: การ์ดสรุปสถานะ

| การ์ด | ความหมาย |
|-------|---------|
| รายการทั้งหมด | จำนวนแถวข้อมูลทั้งหมด |
| พร้อม | แถวที่ผ่านการตรวจสอบ |
| มีคำเตือน | แถวที่ต้องตรวจสอบเพิ่ม |
| ไม่มีรหัสลูกค้า | แถวที่ขาดรหัสลูกค้า |
| ไม่มีงวดบิล | แถวที่ขาดข้อมูลงวด |
| ไม่มีรหัสบริการ | แถวที่ขาดรหัสค่าบริการ |
| ไม่มีน้ำหนัก/จำนวน | แถวที่ขาดข้อมูลปริมาณ |
| ต้องตรวจสอบ | แถวที่ต้องการการอนุมัติพิเศษ |

### ส่วนที่ 3: แท็บข้อมูล (3 แท็บ)

---

#### แท็บที่ 1: ตรวจสอบค่าบริการหลัก (Canonical Charges)

| คอลัมน์ | ความหมาย |
|---------|---------|
| งวดบิล | ช่วงเวลาที่คิดค่าบริการ |
| รหัสลูกค้า | รหัสลูกค้า |
| ชื่อลูกค้า | ชื่อลูกค้า |
| รหัสคลัง | คลังสินค้า |
| จำนวนรับเข้า | ปริมาณที่รับเข้า |
| จำนวนส่งออก | ปริมาณที่ส่งออก |
| คงเหลือ | ปริมาณคงเหลือ |
| ปริมาณที่คิดได้ | ปริมาณสำหรับคิดค่าบริการ |
| น้ำหนักที่คิดได้ | น้ำหนักสำหรับคิดค่าบริการ |
| สถานะตรวจสอบ | ผ่าน / มีข้อผิดพลาด |
| หมายเหตุบัญชี | บันทึกเพิ่มเติม |

---

#### แท็บที่ 2: ตรวจสอบการแมปไป B-Plus

ข้อมูลที่จะส่งออกไประบบบัญชี B-Plus:

| คอลัมน์ | ความหมาย |
|---------|---------|
| รหัสลูกค้า B-Plus | รหัสในระบบบัญชี |
| ชื่อลูกค้า B-Plus | ชื่อในระบบบัญชี |
| งวดบิล B-Plus | งวดในรูปแบบระบบบัญชี |
| รหัสบริการ B-Plus | รหัสประเภทบริการ |
| คำอธิบายบริการ | ชื่อบริการ |
| จำนวน | ปริมาณ |
| น้ำหนัก | น้ำหนัก |
| หน่วย | หน่วยนับ |
| หมายเหตุบัญชี | บันทึก |
| สถานะตรวจสอบ | ผ่าน / มีข้อผิดพลาด |

> **หมายเหตุ:** ข้อมูลในแท็บนี้เป็นตัวอย่างเพื่อตรวจสอบเท่านั้น ยังไม่ได้ส่งออกจริง

---

#### แท็บที่ 3: บันทึกการตรวจสอบ (Validation Logs)

แสดงข้อผิดพลาดและคำเตือนที่พบในข้อมูล เพื่อให้แก้ไขก่อนส่งออก

---

### ส่วนที่ 4: บันทึกการตรวจสอบ (Work Notes)

ช่องให้เจ้าหน้าที่บันทึกหมายเหตุการตรวจสอบ (เก็บเฉพาะในหน้านี้ชั่วคราว)

---

## กฎทางธุรกิจ

1. หน้านี้เป็น **ตัวอย่างเท่านั้น** ไม่มีการส่งข้อมูลออกจริง
2. แถวที่มีสีเตือน (Warning) ต้องแก้ไขก่อนส่งออก
3. บันทึกหมายเหตุ (Work Notes) ไม่บันทึกถาวร — รีเฟรชหน้าจะหาย
