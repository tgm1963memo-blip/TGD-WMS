# เข้าสู่ระบบ Handheld (Handheld Login)

## วัตถุประสงค์
หน้าเข้าสู่ระบบสำหรับอุปกรณ์มือถือและแท็บเล็ตที่ใช้ในคลังสินค้า เจ้าหน้าที่คลังเลือกชื่อตัวเองและกรอก PIN เพื่อยืนยันตัวตน ก่อนเริ่มงานรับสินค้าหรือหยิบสินค้า

## ผู้ใช้งาน
- เจ้าหน้าที่คลังสินค้า (Warehouse Staff)
- ธุรการคลังสินค้า (Warehouse Admin)
- ผู้จัดการคลังสินค้า (Warehouse Manager)

## สิทธิ์ที่ต้องการ
- **Warehouse Staff** ขึ้นไป
- ต้องมีบัญชีในระบบและได้รับ PIN จากผู้ดูแลระบบ

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Barcode / Handheld | ศูนย์สแกน |
| URL | `/handheld` |

---

## คำอธิบายหน้าจอ

หน้า Handheld ออกแบบพิเศษสำหรับหน้าจอขนาดเล็ก (มือถือ/แท็บเล็ต) สีพื้นหลังเข้ม ปุ่มขนาดใหญ่ ใช้งานง่ายในสภาพแวดล้อมคลังสินค้า

### หน้าที่ 1: เลือกพนักงาน (Staff Selection)

แสดงรายชื่อพนักงานทั้งหมดในระบบ:

| ส่วนประกอบ | คำอธิบาย |
|-----------|---------|
| วงกลมตัวอักษร | ตัวย่อชื่อของพนักงาน (เช่น ส.อ.) |
| ชื่อพนักงาน | ชื่อเต็มของพนักงาน |
| บทบาท (Role Badge) | ตำแหน่งของพนักงาน |

**บทบาทที่แสดงในภาษาไทย:**

| รหัสบทบาท | ที่แสดง |
|-----------|--------|
| admin | Admin |
| warehouse_manager | ผจก.คลัง |
| warehouse_admin | ธุรการคลัง |
| warehouse_staff | พนักงานคลัง |
| accounting | บัญชี |

### หน้าที่ 2: กรอก PIN (PIN Entry)

หลังเลือกชื่อ จะเข้าสู่หน้ากรอก PIN:

| ส่วนประกอบ | คำอธิบาย |
|-----------|---------|
| ชื่อพนักงาน | แสดงชื่อที่เลือก |
| จุด PIN (●●●●) | แสดงจำนวนตัวเลขที่กรอก |
| แป้นตัวเลข (1-9, 0) | กดเพื่อกรอก PIN |
| ปุ่ม ⌫ (Backspace) | ลบตัวเลขหลังสุด |
| ปุ่ม OK | ยืนยัน PIN และเข้าสู่ระบบ |
| ปุ่มย้อนกลับ | กลับไปหน้าเลือกพนักงาน |

---

## ขั้นตอนการเข้าสู่ระบบ

**ขั้นตอนที่ 1:** เปิดแอปบนมือถือหรือแท็บเล็ต แล้วไปที่ `/handheld`

**ขั้นตอนที่ 2:** รอระบบโหลดรายชื่อพนักงาน

**ขั้นตอนที่ 3:** แตะที่ชื่อตัวเองในรายการ

**ขั้นตอนที่ 4:** กรอก PIN 4-6 หลักโดยใช้แป้นตัวเลขบนหน้าจอ

**ขั้นตอนที่ 5:** กดปุ่ม **OK** เพื่อยืนยัน

**ขั้นตอนที่ 6:** หากถูกต้อง ระบบจะแสดงหน้าหลักของ Handheld พร้อมเมนู:
- **รับสินค้าเข้า** (Receiving)
- **เบิกสินค้าออก** (Picking)

## ปุ่มทั้งหมด

| ปุ่ม | คำอธิบาย |
|------|---------|
| [ชื่อพนักงาน] | เลือกพนักงานเพื่อเข้าสู่ระบบ |
| 1-9, 0 | กรอกตัวเลข PIN |
| ⌫ (Backspace) | ลบตัวเลขหลังสุด |
| OK | ยืนยัน PIN และเข้าสู่ระบบ |
| ← (Back) | กลับไปหน้าเลือกพนักงาน |

---

## ข้อผิดพลาดที่อาจพบ

| ข้อความ | ความหมาย | การแก้ไข |
|---------|---------|--------|
| PIN ไม่ถูกต้อง | กรอก PIN ผิด | ลองใหม่หรือติดต่อผู้ดูแลระบบ |
| ไม่พบรายชื่อพนักงาน | ระบบโหลดไม่สำเร็จ | ตรวจสอบอินเทอร์เน็ตและลองใหม่ |
| บัญชีถูกระงับ | บัญชีถูกปิด | ติดต่อผู้ดูแลระบบ |

---

## กฎทางธุรกิจ

1. PIN สำหรับ Handheld แยกต่างหากจากรหัสผ่านเข้าเว็บ
2. ผู้ดูแลระบบตั้ง PIN ให้พนักงานผ่านหน้า User Management
3. เจ้าหน้าที่ต้องไม่แชร์ PIN กับผู้อื่น เพราะระบบบันทึกว่าใครดำเนินการอะไร

---

## คำถามที่พบบ่อย

**ถาม:** ลืม PIN ทำอย่างไร?
**ตอบ:** ติดต่อผู้ดูแลระบบเพื่อรีเซ็ต PIN ในหน้า User Management

**ถาม:** ชื่อตัวเองไม่ปรากฏในรายการ ทำอย่างไร?
**ตอบ:** ติดต่อผู้ดูแลระบบให้สร้างบัญชีผู้ใช้ในระบบ

**ถาม:** ระบบค้าง โหลดนาน ทำอย่างไร?
**ตอบ:** ตรวจสอบการเชื่อมต่อ Wi-Fi หรืออินเทอร์เน็ต แล้วรีเฟรชหน้าจอ

---

## แนวปฏิบัติที่ดี

- เข้าสู่ระบบด้วยชื่อของตัวเองเสมอ ห้ามใช้บัญชีผู้อื่น
- ออกจากระบบทุกครั้งเมื่อเลิกใช้งาน
- เก็บ PIN ไว้เป็นความลับ
