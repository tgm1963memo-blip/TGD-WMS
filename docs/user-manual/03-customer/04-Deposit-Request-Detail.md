# รายละเอียดคำขอฝากสินค้า (Deposit Request Detail)

## วัตถุประสงค์
หน้านี้แสดงรายละเอียดครบถ้วนของคำขอฝากสินค้าแต่ละรายการ รวมถึงสถานะ รายการสินค้า ยอดที่รับจริง และประวัติการดำเนินการ

## ผู้ใช้งาน
- ลูกค้า (Customer User)
- ผู้ดูแลระบบ (Admin)

## สิทธิ์ที่ต้องการ
- **Customer User** (เห็นเฉพาะของตนเอง)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal → แจ้งฝากสินค้า | คลิกเลขที่คำขอ |
| URL | `/customer/deposit-request/:requestId` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: สถานะและข้อมูลหัวเอกสาร

| ข้อมูล | ความหมาย |
|--------|---------|
| เลขที่คำขอ | รหัสเฉพาะ |
| สถานะ | Badge สีตามสถานะ |
| วันที่คาดว่าสินค้าจะมาถึง | วันนัดหมาย |
| ผู้ติดต่อ | ชื่อและเบอร์โทร |
| ทะเบียนรถ | ทะเบียนยานพาหนะ |
| หมายเหตุ | ข้อมูลเพิ่มเติม |

### ส่วนที่ 2: Timeline ขั้นตอน

แสดง Timeline สถานะของคำขอ ตั้งแต่ร่างจนถึงรับสินค้าครบ:
- DRAFT → SUBMITTED → REVIEWING → ACCEPTED → RECEIVING → CONFIRMED

### ส่วนที่ 3: ตารางรายการสินค้า

| คอลัมน์ | ความหมาย |
|---------|---------|
| ชื่อสินค้า | สินค้าที่ฝาก |
| เลข LOT | หมายเลข LOT |
| วันผลิต | วันที่ผลิต |
| วันหมดอายุ | วันหมดอายุ |
| จำนวนที่แจ้ง (กล่อง) | จำนวนที่ลูกค้าแจ้งล่วงหน้า |
| น้ำหนักที่แจ้ง (กก.) | น้ำหนักที่แจ้ง |
| จำนวนที่รับจริง (กล่อง) | จำนวนที่เจ้าหน้าที่นับได้จริง |
| น้ำหนักที่รับจริง (กก.) | น้ำหนักจริง |
| Location | ตำแหน่งจัดเก็บในคลัง |

---

## ขั้นตอนการใช้งาน

### ตรวจสอบสถานะคำขอ

**ขั้นตอนที่ 1:** เข้าหน้า Deposit Request List คลิกเลขที่คำขอ

**ขั้นตอนที่ 2:** ดูสถานะปัจจุบันจาก Badge และ Timeline

**ขั้นตอนที่ 3:** ตรวจสอบรายการสินค้าและยอดที่รับจริง

**ขั้นตอนที่ 4:** หากมีข้อสงสัย ใช้ช่องหมายเหตุหรือติดต่อเจ้าหน้าที่

---

## ปุ่มดำเนินการ

| ปุ่ม | เงื่อนไข | คำอธิบาย |
|------|---------|---------|
| แก้ไข (Edit) | DRAFT เท่านั้น | เปิดฟอร์มแก้ไข |
| ส่งคำขอ (Submit) | DRAFT เท่านั้น | ส่งให้เจ้าหน้าที่ตรวจสอบ |
| ยกเลิก (Cancel) | DRAFT, SUBMITTED | ยกเลิกคำขอ |
| พิมพ์/Export | เสมอ | พิมพ์รายการสินค้า |
| คัดลอก (Copy) | เสมอ | สร้างคำขอใหม่จากนี้ |

---

## กฎทางธุรกิจ

1. เมื่อยืนยันรับสินค้าแล้ว (RECEIVED_CONFIRMED) ไม่สามารถแก้ไขได้
2. ยอดที่รับจริงอาจต่างจากที่แจ้ง — ยอดจริงคือฐานสต๊อก
3. ตรวจสอบ Location จัดเก็บจากตารางนี้หากต้องการทราบว่าสินค้าอยู่ที่ไหน
