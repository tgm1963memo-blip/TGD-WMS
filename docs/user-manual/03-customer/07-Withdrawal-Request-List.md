# รายการคำขอเบิกสินค้า (Withdrawal Request List)

## วัตถุประสงค์
หน้านี้แสดงรายการคำขอเบิกสินค้าทั้งหมดของลูกค้า ให้ติดตามสถานะและดำเนินการกับคำขอต่างๆ

## ผู้ใช้งาน
- ลูกค้า (Customer User)
- ผู้ดูแลระบบ (Admin) — ดูแทนลูกค้าได้

## สิทธิ์ที่ต้องการ
- **Customer User**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal | แจ้งเบิกสินค้า |
| URL | `/customer/withdrawal-request` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ปุ่มหลัก
- **สร้างคำขอเบิกแบบร่าง** — สร้างคำขอใหม่

### ส่วนที่ 2: ช่องค้นหา
พิมพ์ค้นหาด้วย: เลขที่ใบขอเบิก, สถานะ, ประเภทการส่ง, ผู้ติดต่อ, ปลายทาง

### ส่วนที่ 3: ตารางรายการ

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่ใบขอเบิก | รหัสเฉพาะ |
| ชื่อลูกค้า | (Admin เท่านั้น) |
| สถานะ | Badge สีตามสถานะ |
| วันที่ขอส่งออก | วันที่ต้องการ |
| ประเภทการส่ง | PICKUP / DELIVERY |
| ผู้ติดต่อ | ชื่อผู้รับ |
| ปลายทาง | ที่อยู่ส่ง |
| หมายเหตุ | ข้อมูลเพิ่มเติม |
| เวลาดำเนินการล่าสุด | เวลาที่อัปเดตล่าสุด |
| การดำเนินการ | ปุ่มต่างๆ |

---

## ปุ่มดำเนินการต่อรายการ

| ปุ่ม | เงื่อนไข | คำอธิบาย |
|------|---------|---------|
| ดูรายละเอียด | เสมอ | เปิดหน้ารายละเอียด (หรือ Modal) |
| แก้ไข | DRAFT เท่านั้น | เปิดฟอร์มแก้ไข |
| คัดลอก | เสมอ | สร้างคำขอใหม่จากข้อมูลเดิม |
| ลบ | DRAFT เท่านั้น | ลบคำขอ (ต้องยืนยัน) |
| พิมพ์ | เสมอ | พิมพ์เอกสารคำขอเบิก |

---

## สถานะทั้งหมด

| สถานะ | ความหมาย | สี |
|------|----------|-----|
| DRAFT (ร่าง) | สร้างแล้ว ยังไม่ส่ง | เทา |
| SUBMITTED_BY_CUSTOMER | ส่งแล้ว รอตรวจสอบ | ฟ้า |
| ADMIN_REVIEWING | ธุรการกำลังตรวจสอบ | เหลือง |
| ADMIN_ACCEPTED | อนุมัติแล้ว รอหยิบ | เขียวอ่อน |
| WAREHOUSE_PICKING (กำลังจัดสินค้า) | เจ้าหน้าที่กำลังหยิบ | ฟ้าเข้ม |
| COMPLETED (เสร็จสิ้น) | หยิบและส่งออกแล้ว | เขียวเข้ม |
| DISPATCHED (ส่งออกแล้ว) | สินค้าออกจากคลัง | เขียว |
| REJECTED (ถูกปฏิเสธ) | ถูกปฏิเสธ | แดง |
| CANCELLED (ยกเลิก) | ยกเลิก | เทาเข้ม |

---

## กฎทางธุรกิจ

1. ลบได้เฉพาะสถานะ DRAFT
2. แก้ไขได้เฉพาะสถานะ DRAFT
3. การคัดลอกสร้างคำขอใหม่เป็น DRAFT

---

## คำถามที่พบบ่อย

**ถาม:** สถานะค้างอยู่ที่ WAREHOUSE_PICKING นานมาก ทำไม?
**ตอบ:** เจ้าหน้าที่คลังอาจยังหยิบสินค้าไม่เสร็จ ติดต่อธุรการคลัง

**ถาม:** คำขอถูกปฏิเสธ (REJECTED) ทำอย่างไรต่อ?
**ตอบ:** ดูเหตุผลการปฏิเสธในรายละเอียด แล้วสร้างคำขอใหม่โดยแก้ไขข้อมูล
