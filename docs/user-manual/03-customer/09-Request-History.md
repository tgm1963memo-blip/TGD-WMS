# ประวัติคำขอ (Request History)

## วัตถุประสงค์
หน้านี้แสดงประวัติคำขอทั้งหมดของลูกค้า ทั้งคำขอฝากและเบิกสินค้า ในหน้าเดียว เพื่อการติดตามและอ้างอิงย้อนหลัง

## ผู้ใช้งาน
- ลูกค้า (Customer User)

## สิทธิ์ที่ต้องการ
- **Customer User**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal | ประวัติคำขอ |
| URL | `/customer/requests` |

---

## คำอธิบายหน้าจอ

### แท็บประเภทคำขอ

| แท็บ | ข้อมูลที่แสดง |
|------|-------------|
| คำขอฝากสินค้า | ประวัติการฝากสินค้าทั้งหมด |
| คำขอเบิกสินค้า | ประวัติการเบิกสินค้าทั้งหมด |

### ตาราง

**คำขอฝาก:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่คำขอ | รหัสคำขอฝาก |
| สถานะ | สถานะปัจจุบัน |
| วันที่คาดว่าสินค้าจะมาถึง | วันนัดหมาย |
| วันที่สร้าง | วันที่สร้างคำขอ |
| ผู้ติดต่อ | ชื่อผู้ส่ง |

**คำขอเบิก:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่ใบขอเบิก | รหัสคำขอเบิก |
| สถานะ | สถานะปัจจุบัน |
| วันที่ขอส่งออก | วันที่ต้องการ |
| ประเภทการส่ง | PICKUP / DELIVERY |
| วันที่สร้าง | วันที่สร้างคำขอ |

---

## ขั้นตอนการใช้งาน

**ขั้นตอนที่ 1:** ไปที่ Customer Portal → ประวัติคำขอ

**ขั้นตอนที่ 2:** เลือกแท็บ "คำขอฝากสินค้า" หรือ "คำขอเบิกสินค้า"

**ขั้นตอนที่ 3:** ค้นหาหรือเลื่อนดูรายการ

**ขั้นตอนที่ 4:** คลิกที่รายการเพื่อดูรายละเอียด

---

## กฎทางธุรกิจ

1. แสดงประวัติทั้งหมดตั้งแต่เริ่มใช้งานระบบ
2. ลูกค้าเห็นเฉพาะคำขอของตนเอง
3. ไม่สามารถแก้ไขหรือลบประวัติได้จากหน้านี้

---

## แนวปฏิบัติที่ดี

- ใช้หน้าประวัติเพื่อตรวจสอบว่าคำขอเก่าดำเนินการเสร็จหรือยัง
- อ้างอิงเลขที่คำขอเมื่อติดต่อสอบถามเจ้าหน้าที่
