# รายการคำขอฝากสินค้า (Deposit Request List)

## วัตถุประสงค์
หน้านี้แสดงรายการคำขอฝากสินค้าทั้งหมดของลูกค้า ทั้งที่กำลังดำเนินการ เสร็จสิ้น หรือยกเลิก พร้อมฟังก์ชันสร้างใหม่ แก้ไข คัดลอก และลบ

## ผู้ใช้งาน
- ลูกค้า (Customer User)
- ผู้ดูแลระบบ (Admin) — ดูแทนลูกค้าได้

## สิทธิ์ที่ต้องการ
- **Customer User**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal | แจ้งฝากสินค้า |
| URL | `/customer/deposit-request` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ปุ่มหลัก
- **สร้างคำขอฝากสินค้าแบบร่าง** — สร้างคำขอใหม่

### ส่วนที่ 2: ช่องค้นหา
พิมพ์ค้นหาด้วย: เลขที่คำขอ, สถานะ, หมายเหตุ, ชื่อลูกค้า

### ส่วนที่ 3: ตารางรายการ

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่คำขอ | รหัสประจำคำขอฝาก |
| ชื่อลูกค้า | (Admin เท่านั้น) ชื่อลูกค้า |
| สถานะ | Badge สีตามสถานะปัจจุบัน |
| วันที่คาดว่าสินค้าจะมาถึง | วันนัดหมาย |
| ผู้ติดต่อ | ชื่อผู้ส่ง |
| เบอร์โทร | เบอร์ผู้ติดต่อ |
| หมายเหตุ | ข้อความเพิ่มเติม |
| เวลาดำเนินการล่าสุด | วันและเวลาที่แก้ไขล่าสุด |
| การดำเนินการ | ปุ่ม ดู/แก้ไข/คัดลอก/ลบ |

---

## ปุ่มดำเนินการต่อรายการ

| ปุ่ม | เงื่อนไข | คำอธิบาย |
|------|---------|---------|
| ดูรายละเอียด | เสมอ | เปิดหน้ารายละเอียดคำขอ |
| แก้ไข | DRAFT เท่านั้น | เปิดฟอร์มแก้ไข |
| คัดลอก (Copy) | เสมอ | สร้างคำขอใหม่จากข้อมูลเดิม |
| ลบ | DRAFT, SUBMITTED, REVIEWING | ลบคำขอ (ต้องยืนยัน) |

---

## สถานะทั้งหมด

| สถานะ | ความหมาย | สี |
|------|----------|-----|
| DRAFT (ร่าง) | สร้างแล้ว ยังไม่ส่ง | เทา |
| SUBMITTED_BY_CUSTOMER | ส่งแล้ว รอตรวจสอบ | ฟ้า |
| ADMIN_REVIEWING | เจ้าหน้าที่กำลังตรวจสอบ | เหลือง |
| ADMIN_ACCEPTED | อนุมัติแล้ว | เขียว |
| WAREHOUSE_RECEIVING | กำลังรับสินค้า | ฟ้าเข้ม |
| RECEIVED_CONFIRMED | รับสินค้าครบแล้ว | เขียวเข้ม |
| CUSTOMER_NOTIFIED | แจ้งลูกค้าแล้ว | เขียว |
| REJECTED | ถูกปฏิเสธ | แดง |
| CANCELLED | ยกเลิก | เทาเข้ม |

---

## กฎทางธุรกิจ

1. แสดง 5 รายการต่อหน้า (Pagination)
2. สามารถลบได้เฉพาะ DRAFT, SUBMITTED, REVIEWING
3. สามารถแก้ไขได้เฉพาะ DRAFT
4. การคัดลอก (Copy) สร้างคำขอใหม่เป็น DRAFT โดยอัตโนมัติ

---

## คำถามที่พบบ่อย

**ถาม:** ลบคำขอไม่ได้ ทำอย่างไร?
**ตอบ:** ตรวจสอบสถานะ — ลบได้เฉพาะ DRAFT, SUBMITTED, REVIEWING เท่านั้น

**ถาม:** จะสร้างคำขอที่คล้ายกับคำขอเก่าได้อย่างไร?
**ตอบ:** กดปุ่ม "คัดลอก" ในแถวคำขอเดิม ระบบสร้างคำขอใหม่ให้พร้อมข้อมูลเดิม
