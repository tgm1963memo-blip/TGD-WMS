# รายละเอียดคำขอเบิกสินค้า (Withdrawal Request Detail)

## วัตถุประสงค์
หน้านี้แสดงรายละเอียดคำขอเบิกสินค้าแต่ละรายการ รวมถึงสถานะปัจจุบัน รายการสินค้า และสถานะการหยิบสินค้าของแต่ละรายการ

## ผู้ใช้งาน
- ลูกค้า (Customer User)
- ผู้ดูแลระบบ (Admin)

## สิทธิ์ที่ต้องการ
- **Customer User** (เห็นเฉพาะของตนเอง)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal → แจ้งเบิกสินค้า | คลิกเลขที่ใบขอเบิก |
| URL | `/customer/withdrawal-request/:requestId` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ข้อมูลหัวเอกสาร

| ข้อมูล | ความหมาย |
|--------|---------|
| เลขที่ใบขอเบิก | รหัสเฉพาะ |
| สถานะ | Badge สีตามสถานะ |
| วันที่ขอส่งออก | วันที่ต้องการ |
| ประเภทการส่ง | PICKUP / DELIVERY |
| ผู้ติดต่อ | ชื่อและเบอร์ |
| ปลายทาง | ที่อยู่ส่ง |
| หมายเหตุ | ข้อมูลเพิ่มเติม |

### ส่วนที่ 2: Timeline ขั้นตอน

แสดงความคืบหน้าของคำขอ:
DRAFT → SUBMITTED → REVIEWING → ACCEPTED → PICKING → COMPLETED

### ส่วนที่ 3: ตารางรายการสินค้า

| คอลัมน์ | ความหมาย |
|---------|---------|
| ชื่อสินค้า | สินค้าที่ขอเบิก |
| รหัสสินค้า | รหัสประจำสินค้า |
| LOT No | หมายเลข LOT |
| จำนวนที่ขอ (กล่อง) | จำนวนที่ต้องการ |
| น้ำหนักที่ขอ (กก.) | น้ำหนักที่ต้องการ |
| จำนวนที่หยิบได้ (กล่อง) | จำนวนที่เจ้าหน้าที่หยิบจริง |
| น้ำหนักที่หยิบได้ (กก.) | น้ำหนักที่หยิบจริง |
| สถานะการหยิบ | รอดำเนินการ / จัดแล้ว |

---

## ปุ่มดำเนินการ

| ปุ่ม | เงื่อนไข | คำอธิบาย |
|------|---------|---------|
| แก้ไข | DRAFT เท่านั้น | เปิดฟอร์มแก้ไข |
| ส่งคำขอ | DRAFT เท่านั้น | ส่งให้เจ้าหน้าที่ |
| ยกเลิก | DRAFT, SUBMITTED | ยกเลิกคำขอ |
| คัดลอก | เสมอ | สร้างคำขอใหม่ |
| พิมพ์ | เสมอ | พิมพ์เอกสาร |

---

## สถานะการหยิบสินค้าต่อรายการ

| สถานะ | ความหมาย | สี |
|------|----------|-----|
| รอดำเนินการ | ยังไม่หยิบ | เทา |
| จัดแล้ว | หยิบเสร็จแล้ว | เขียว |

---

## กฎทางธุรกิจ

1. เมื่อหยิบสินค้าครบและยืนยันส่งออกแล้ว ไม่สามารถยกเลิกได้
2. จำนวนที่หยิบจริงอาจต่างจากที่ขอ
3. ตรวจสอบ "สถานะการหยิบ" เพื่อทราบว่าสินค้าพร้อมส่งหรือยัง
