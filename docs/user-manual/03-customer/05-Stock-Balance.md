# ยอดคงเหลือสินค้า — พอร์ทัลลูกค้า (Customer Stock Balance)

## วัตถุประสงค์
หน้านี้ให้ลูกค้าตรวจสอบยอดสินค้าคงเหลือในคลัง แสดงรายละเอียดแต่ละล็อต พร้อมจำนวนกล่องและน้ำหนักที่ยังมีอยู่ในคลัง

## ผู้ใช้งาน
- ลูกค้า (Customer User)
- ผู้ดูแลระบบ (Admin) — ดูแทนลูกค้าได้

## สิทธิ์ที่ต้องการ
- **Customer User**

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Customer Portal | ยอดคงเหลือลูกค้า |
| URL | `/customer/stock-balance` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: สรุปยอดรวม

| ข้อมูล | คำอธิบาย |
|--------|---------|
| จำนวนประเภทสินค้า | X รายการ |
| กล่องคงเหลือรวม | XXX กล่อง |
| น้ำหนักคงเหลือรวม | XXX กก. |
| จำนวนใบฝาก | X รายการ (ที่มียอดคงเหลือ) |

### ส่วนที่ 2: ตารางยอดคงเหลือ

จัดกลุ่มตามประเภทสินค้า:

| คอลัมน์ | ความหมาย |
|---------|---------|
| รหัสสินค้า | รหัสของสินค้า |
| ชื่อสินค้า | ชื่อเต็มของสินค้า |
| ประเภท | FROZEN / CHILLED / AMBIENT |
| กล่องคงเหลือ (กล่อง) | จำนวนกล่องที่ยังอยู่ในคลัง |
| น้ำหนัก (กก.) | น้ำหนักที่ยังอยู่ในคลัง |

**ขยายดูรายละเอียดแต่ละใบฝาก:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| เลขที่ใบฝาก | รหัสคำขอฝากสินค้า |
| วันที่รับเข้า | วันที่รับสินค้าจริง |
| LOT No | หมายเลข LOT |
| กล่องที่รับ | จำนวนกล่องที่รับมา |
| กล่องที่เบิกออก | จำนวนที่เบิกออกไปแล้ว |
| คงเหลือ (กล่อง) | กล่องที่รับ - กล่องที่เบิกออก |

---

## ขั้นตอนการตรวจสอบ

**ขั้นตอนที่ 1:** ไปที่ Customer Portal → ยอดคงเหลือลูกค้า

**ขั้นตอนที่ 2:** ดูสรุปยอดรวมที่ด้านบน

**ขั้นตอนที่ 3:** ขยายดูรายการสินค้าที่ต้องการ (คลิก ▼)

**ขั้นตอนที่ 4:** ขยายดูรายละเอียดแต่ละใบฝาก/LOT

---

## สูตรการคำนวณ

```
ยอดคงเหลือ = สินค้าที่รับเข้า - สินค้าที่เบิกออก (ที่ยืนยันแล้ว)
```

> แสดงเฉพาะรายการที่มียอดคงเหลือ > 0

---

## กฎทางธุรกิจ

1. ลูกค้าเห็นเฉพาะสินค้าของตนเองเท่านั้น
2. ยอดคงเหลือเป็นข้อมูลจริง (Real-time)
3. สินค้าที่อยู่ระหว่างรับเข้ายังไม่นับรวม ต้องยืนยันรับก่อน
4. สินค้าที่อยู่ระหว่างเบิกออก (WAREHOUSE_PICKING) **ยังไม่ถูกหักออก** จากยอด

---

## คำถามที่พบบ่อย

**ถาม:** สินค้าของฉันอยู่ที่ไหนในคลัง?
**ตอบ:** ดูคอลัมน์ Location ในตารางรายละเอียดใบฝาก หรือติดต่อเจ้าหน้าที่คลัง

**ถาม:** ยอดคงเหลือต่างจากที่คิดไว้ ทำไม?
**ตอบ:** ตรวจสอบรายการเบิกออก (Withdrawal) ที่ยืนยันแล้ว ใน "ประวัติคำขอ"

---

## แนวปฏิบัติที่ดี

- ตรวจสอบยอดคงเหลือก่อนสร้างคำขอเบิกสินค้า
- หากพบยอดไม่ตรง ติดต่อเจ้าหน้าที่คลังทันที
