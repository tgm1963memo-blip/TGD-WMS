# ยอดคงเหลือสินค้า (Inventory Balance)

## วัตถุประสงค์
หน้านี้แสดงยอดคงเหลือสินค้าในคลังของลูกค้าทุกราย โดยคำนวณจากสินค้าที่รับเข้าคลังหักด้วยการเบิกที่ยืนยันแล้ว แสดงเฉพาะรายการที่มียอดคงเหลือมากกว่าศูนย์

## ผู้ใช้งาน
- ธุรการคลังสินค้า (Warehouse Admin)
- ผู้จัดการคลังสินค้า (Warehouse Manager)
- ผู้ดูแลระบบ (Admin)
- นักบัญชี (Accounting)

## สิทธิ์ที่ต้องการ
- **Warehouse Admin** ขึ้นไป (สำหรับดูยอดคงเหลือทั้งหมด)
- **Viewer** (สำหรับดูรายงาน)

## การเข้าถึง

| เมนู | เส้นทาง |
|------|---------|
| Inventory Control | ยอดคงเหลือ |
| URL | `/inventory` |

---

## คำอธิบายหน้าจอ

### ส่วนที่ 1: ตัวกรอง (Filters)

| ตัวกรอง | คำอธิบาย |
|---------|---------|
| เลือกลูกค้า | กรองยอดคงเหลือตามลูกค้า (เลือก "ลูกค้าทุกราย" เพื่อดูทั้งหมด) |
| ค้นหา | พิมพ์ชื่อสินค้า รหัสสินค้า หรือรหัสลูกค้า |

### ส่วนที่ 2: สรุปยอดรวม

แสดงผลรวมสำหรับลูกค้าที่เลือก:
- จำนวนลูกค้า (X ราย)
- จำนวนประเภทสินค้า (X รายการ)
- กล่องคงเหลือรวม (XXX กล่อง)
- น้ำหนักคงเหลือรวม (XXX กก.)

### ส่วนที่ 3: ตารางยอดคงเหลือ

จัดกลุ่มตามลูกค้า แล้วแสดงรายการสินค้าภายในแต่ละลูกค้า:

**ระดับลูกค้า:**

| คอลัมน์ | ความหมาย |
|---------|---------|
| ชื่อลูกค้า | ชื่อบริษัท/ลูกค้า |
| รวมกล่อง | จำนวนกล่องรวมทุกสินค้า |
| รวมน้ำหนัก | น้ำหนักรวมทุกสินค้า |
| จำนวนประเภทสินค้า | จำนวนรายการสินค้าที่มีในคลัง |

**ระดับสินค้า (ขยาย):**

| คอลัมน์ | ความหมาย |
|---------|---------|
| รหัสสินค้า | รหัสประจำสินค้า |
| ชื่อสินค้า | ชื่อสินค้าเต็ม |
| ประเภท | FROZEN / CHILLED / AMBIENT |
| กล่องคงเหลือ | จำนวนกล่องที่คงเหลือ |
| น้ำหนัก (กก.) | น้ำหนักที่คงเหลือ |
| จำนวนใบฝาก | จำนวนล็อตที่มีในคลัง |

**ระดับล็อต (ขยายเพิ่ม):**

แสดงรายละเอียดแต่ละใบฝาก/ล็อต:
- เลขที่ใบฝาก
- วันที่รับเข้า
- LOT No
- กล่องที่รับ vs กล่องที่เบิกออก
- กล่องคงเหลือ

---

## ขั้นตอนการตรวจสอบยอดคงเหลือ

**ขั้นตอนที่ 1:** เข้าเมนู **Inventory Control → ยอดคงเหลือ**

**ขั้นตอนที่ 2:** เลือกลูกค้าจากตัวกรอง หรือเลือก "ลูกค้าทุกราย" เพื่อดูทั้งหมด

**ขั้นตอนที่ 3:** ดูสรุปยอดรวมที่ด้านบน

**ขั้นตอนที่ 4:** คลิกที่ชื่อลูกค้าหรือ ▼ เพื่อขยายดูรายการสินค้า

**ขั้นตอนที่ 5:** คลิกที่รายการสินค้าเพื่อขยายดูรายละเอียดแต่ละล็อต

---

## สูตรการคำนวณยอดคงเหลือ

```
ยอดคงเหลือ = สินค้าที่รับเข้า - สินค้าที่เบิกออก (ที่ยืนยันแล้ว)
```

> เฉพาะรายการที่มียอดคงเหลือ > 0 เท่านั้นที่แสดงในตาราง

---

## ปุ่มและการดำเนินการ

| ปุ่ม | คำอธิบาย |
|------|---------|
| ▶ / ▼ ขยายทั้งหมด | ขยาย/ยุบข้อมูลลูกค้าทั้งหมด |
| คลิกที่แถวลูกค้า | ขยาย/ยุบรายการสินค้าของลูกค้านั้น |
| คลิกที่รายการสินค้า | ขยาย/ยุบรายละเอียดล็อต |

---

## กฎทางธุรกิจ

1. ยอดคงเหลือคำนวณจากสินค้าที่รับเข้าจริง (ยืนยันแล้ว) หักด้วยการเบิกที่ยืนยันแล้วเท่านั้น
2. การเบิกที่ยังเป็น DRAFT หรือ PENDING **ไม่ถูกหักออก** จากยอดคงเหลือ
3. รายการที่ยอดคงเหลือ = 0 จะไม่แสดงในหน้านี้
4. ยอดคงเหลือแสดงเป็นรายลูกค้า ลูกค้าแต่ละรายจะเห็นเฉพาะสินค้าของตน

---

## คำถามที่พบบ่อย

**ถาม:** ยอดคงเหลือไม่ตรงกับที่ลูกค้าแจ้ง ต้องทำอย่างไร?
**ตอบ:** ตรวจสอบรายการเบิกสินค้า (Withdrawal) ที่ยืนยันแล้วว่าถูกต้องหรือไม่ และตรวจสอบรายการรับสินค้า (Receiving) ที่ยืนยันแล้ว

**ถาม:** สินค้าของลูกค้าหายไปจากรายการ ทำไม?
**ตอบ:** อาจเป็นเพราะยอดคงเหลือเป็นศูนย์ (สินค้าเบิกออกทั้งหมดแล้ว) ตรวจสอบประวัติการเคลื่อนไหวที่เมนู Reports → บัญชีความเคลื่อนไหว

---

## แนวปฏิบัติที่ดี

- ตรวจสอบยอดคงเหลือสม่ำเสมอ อย่างน้อยสัปดาห์ละครั้ง
- ใช้ตัวกรองลูกค้าเพื่อดูยอดของลูกค้าแต่ละราย
- แจ้งลูกค้าทันทีหากพบว่ายอดไม่ตรง
