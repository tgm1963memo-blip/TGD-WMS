# Controlled Rollout Communication Template

## Purpose

เอกสารนี้เป็นแม่แบบการสื่อสารสำหรับการเริ่มใช้งานแบบควบคุม (Controlled Rollout) ของระบบ TGD WMS

## Pre-rollout Announcement

หัวข้อ: แจ้งเตรียมเริ่มใช้งาน TGD WMS แบบควบคุม

เรียน ทีมงานที่เกี่ยวข้อง

ระบบ TGD WMS จะเริ่มการใช้งานแบบควบคุมในวันที่ [ระบุวันที่] เวลา [ระบุเวลา]

ขอบเขตการใช้งาน Day 1:

- Receiving
- Putaway
- Transfer
- Adjustment
- Stock Count
- Customer Withdrawal
- Allocation
- Picking
- Dispatch / Goods Issue
- Reports
- Monthly Storage Billing Summary
- Accounting Charge Review แบบตรวจสอบเท่านั้น

รายการที่ยังไม่เปิดใช้:

- Invoice generation
- Accounting post
- Live ERP connector
- ERP inventory sync
- Express sync
- Production logo upload
- Production branding persistence

กรุณาใช้งานตาม SOP และแจ้งปัญหาผ่านช่องทาง support ที่กำหนด

## Day 1 Start Announcement

หัวข้อ: เริ่ม Day 1 Controlled Rollout ของ TGD WMS

เรียน ผู้ใช้งาน Day 1

ขณะนี้เริ่มการใช้งาน TGD WMS แบบควบคุมแล้ว กรุณา:

1. เข้าระบบด้วยบัญชีที่ได้รับอนุมัติ
2. ใช้งานเฉพาะ module ที่ได้รับอนุญาต
3. บันทึกหลักฐานตามขั้นตอน
4. แจ้งปัญหาทันทีเมื่อพบความผิดปกติ
