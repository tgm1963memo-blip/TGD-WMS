This board tracks defects found during the first 1-5 days of controlled rollout.

## Status Definitions

| Status | Meaning |
| --- | --- |
| New | Issue logged but not yet triaged |
| In Review | Owner is reviewing impact and cause |
| Fix Planned | Fix or mitigation is planned |
| Fixed | Fix completed and waiting for retest |
| Retest | Retest in progress |
| Closed | Retest passed or issue accepted as resolved |
| Deferred | Accepted for later sprint and not blocking current rollout |
