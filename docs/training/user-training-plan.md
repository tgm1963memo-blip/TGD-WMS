# แผนการอบรมผู้ใช้งาน TGD WMS

## วัตถุประสงค์การอบรม

เอกสารนี้ใช้วางแผนการอบรมผู้ใช้งาน TGD WMS สำหรับช่วง UAT และการเตรียมใช้งานจริงในอนาคต ระบบนี้เป็นระบบคลังเย็น (Cold Storage) สำหรับรับฝากสินค้า จัดเก็บสินค้า และจ่ายสินค้าออกตามคำขอเบิกของลูกค้า โดยสินค้าเป็นทรัพย์สินของลูกค้า (Customer-owned inventory)

## ขอบเขตการอบรม

- ภาพรวมการใช้งานระบบ TGD WMS
- การรับเข้าสินค้า (Receiving)
- การนำสินค้าเข้าที่จัดเก็บ (Putaway)
- การโอนย้ายภายในคลัง (Transfer)
- การปรับปรุงสินค้าคงคลัง (Adjustment)
- การตรวจนับสินค้า (Stock Count)
- การเบิกสินค้าโดยลูกค้า (Customer Withdrawal)
- การจัดสรรสินค้า (Allocation)
- การหยิบสินค้า (Picking)
- การจ่ายสินค้าออก (Dispatch / Goods Issue)
- การตรวจสอบรายงานคลังสินค้า
- รายงานสรุปค่าบริการจัดเก็บรายเดือน (Monthly Storage Billing Summary)
- การตรวจสอบข้อมูลค่าบริการส่งต่อบัญชี (Accounting Charge Review)
- การใช้งานสิทธิ์ตามบทบาทและการสลับภาษาไทย/อังกฤษ
- การบันทึกหลักฐานและการแจ้งปัญหาระหว่าง UAT

สิ่งที่ไม่อยู่ในขอบเขตการอบรมนี้:

- การสร้างใบแจ้งหนี้
- การบันทึกบัญชี
- การเชื่อมต่อ ERP แบบใช้งานจริง
- การซิงก์สินค้าคงคลังกับ ERP
- การซิงก์ Express
- การดูแลฐานข้อมูลหรือการแก้ไขระบบเชิงเทคนิค

## กลุ่มผู้เข้าอบรม

- `warehouse_manager` ผู้จัดการคลัง
- `warehouse_staff` เจ้าหน้าที่คลัง
- `accounting` เจ้าหน้าที่บัญชี
- `viewer` ผู้ดูรายงาน
- `admin` ผู้ดูแลระบบ / controller

## สมมติฐานสภาพแวดล้อมการอบรม

- ใช้ระบบ staging หรือ UAT เท่านั้น
- ข้อมูลอบรมแยกจากข้อมูลจริง
- มีผู้ใช้ทดสอบครบตามบทบาทที่กำหนด
- ภาษาเริ่มต้นของระบบเป็นภาษาไทย
- สามารถสลับเป็นภาษาอังกฤษเพื่อการตรวจสอบได้
- ไม่มีการเปิดใช้งาน ERP live connector, inventory sync, invoice generation, accounting post หรือ Express sync

## ข้อมูลที่ต้องเตรียมสำหรับอบรม

- รายชื่อลูกค้า
- สินค้า/SKU
- คลัง ห้องเย็น โซน และตำแหน่งจัดเก็บ
- พาเลทและล็อต
- ยอดสินค้าเริ่มต้น
- ตัวอย่างเอกสารรับเข้า
- ตัวอย่างคำขอเบิกสินค้าโดยลูกค้า
- สมมติฐานค่าบริการจัดเก็บและตัวอย่าง Operation Charge
- ผู้ใช้งานทดสอบตามบทบาท

## วิธีการอบรม

- ผู้สอนอธิบายภาพรวมกระบวนการ
- สาธิตการใช้งานตาม SOP
- ผู้เข้าอบรมทดลองทำตาม UAT scenario
- ฝึกบันทึกผลจริง หลักฐาน และ defect
- ถามตอบและสรุปข้อควรระวัง

## หน้าที่ของผู้สอน

- เตรียมระบบและข้อมูลอบรม
- อธิบายขอบเขตธุรกิจและสิ่งที่ไม่อยู่ในขอบเขต
- สาธิตขั้นตอนตาม SOP
- ตรวจสอบว่าผู้ใช้งานเข้าใจการเก็บหลักฐาน
- บันทึกผู้เข้าอบรมและประเด็นที่พบ

## หน้าที่ของผู้เข้าอบรม

- เข้าร่วมการอบรมตามรอบที่กำหนด
- ใช้บทบาทผู้ใช้ที่ได้รับมอบหมาย
- ทำตามขั้นตอนใน SOP และ UAT script
- บันทึกผลจริงและหลักฐาน
- แจ้งปัญหาหรือขั้นตอนที่ไม่ชัดเจน

## เกณฑ์จบการอบรม

- ผู้ใช้งานเข้าร่วมการอบรมครบตามหัวข้อที่เกี่ยวข้อง
- ผู้ใช้งานทดลองทำ flow ที่ได้รับมอบหมายแล้ว
- ผู้ใช้งานเข้าใจการบันทึกหลักฐานและการแจ้งปัญหา
- ผู้ใช้งานเข้าใจข้อจำกัดของระบบและสิ่งที่ไม่อยู่ในขอบเขต
