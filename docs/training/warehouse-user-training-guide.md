# คู่มืออบรมผู้ใช้งานคลังสินค้า

## ภาพรวมระบบสำหรับผู้ใช้งานคลัง

TGD WMS ใช้สำหรับงานคลังเย็น (Cold Storage) โดยดูแลสินค้าที่ลูกค้านำมาฝาก ระบบช่วยบันทึกการรับเข้า การจัดเก็บ การโอนย้าย การตรวจนับ การเบิกสินค้าโดยลูกค้า และการจ่ายสินค้าออก สินค้าทั้งหมดเป็นสินค้าของลูกค้า ไม่ใช่สินค้าที่ TGD ขายเอง

## การรับเข้าสินค้า (Receiving)

1. เปิดหน้าการรับเข้าสินค้า (Receiving)
2. สร้างหรือเปิดเอกสารรับเข้าสินค้าฝาก (Goods Deposit)
3. ตรวจสอบลูกค้า สินค้า/SKU ล็อต พาเลท จำนวน หน่วยนับ และคลัง
4. หากพบจำนวนหรือข้อมูลไม่ตรง ให้บันทึกปัญหาก่อนยืนยัน
5. ยืนยันเอกสารเฉพาะกรณีที่อยู่ใน workflow ที่ได้รับอนุมัติแล้วเท่านั้น

## การนำสินค้าเข้าที่จัดเก็บ (Putaway)

1. เปิดหน้าการนำสินค้าเข้าที่จัดเก็บ (Putaway)
2. เลือกรายการสินค้าที่รับเข้าแล้ว
3. ตรวจสอบเลขอ้างอิงเอกสารรับเข้า
4. เลือกห้องเย็น โซน และตำแหน่งจัดเก็บ
5. ตรวจสอบว่าพาเลทหรือสินค้าอยู่ในตำแหน่งจริง
6. ตรวจสอบยอด stock balance และ movement ledger หลังดำเนินการ

## การโอนย้ายภายในคลัง (Transfer)

1. ค้นหาสินค้าของลูกค้าที่ต้องการโอนย้าย
2. ตรวจสอบลูกค้า สินค้า ล็อต พาเลท และตำแหน่งต้นทาง
3. เลือกตำแหน่งปลายทาง
4. ตรวจสอบข้อมูลก่อนยืนยันการโอนย้าย
5. ตรวจสอบยอดคงเหลือตามตำแหน่งหลังทำรายการ

## การปรับปรุงสินค้าคงคลัง (Adjustment)

1. ระบุสินค้าที่ต้องปรับปรุง
2. เลือกประเภทการปรับปรุงและเหตุผล
3. ระบุจำนวนและหน่วยนับให้ถูกต้อง
4. แนบหมายเหตุหรือหลักฐานตามความจำเป็น
5. ให้ผู้จัดการคลังตรวจสอบก่อนดำเนินการตามกรณี
6. ตรวจสอบ movement ledger หลังการปรับปรุงที่ได้รับอนุมัติ

## การตรวจนับสินค้า (Stock Count)

1. เปิดหน้า Stock Count
2. เลือกขอบเขตการตรวจนับ เช่น คลัง ตำแหน่ง สินค้า ล็อต หรือพาเลท
3. นับจำนวนจริง
4. บันทึกจำนวนที่นับได้
5. เปรียบเทียบจำนวนในระบบกับจำนวนจริง
6. หากมีผลต่าง ให้ส่งให้ผู้จัดการคลังตรวจสอบ
7. สร้าง adjustment draft เฉพาะกรณีที่ได้รับอนุมัติตามขั้นตอน

## การเบิกสินค้าโดยลูกค้า (Customer Withdrawal)

1. เปิดหน้า Customer Withdrawal
2. สร้างหรือเปิดคำขอเบิกสินค้า
3. ตรวจสอบลูกค้า วันที่ต้องการจ่ายสินค้า สินค้า ล็อต จำนวน และหน่วยนับ
4. ตรวจสอบว่าสินค้าที่จะเบิกเป็นสินค้าของลูกค้ารายนั้นจริง

## การจัดสรรสินค้า (Allocation)

1. เปิดหน้า Allocation
2. เลือกคำขอเบิกสินค้า
3. จัดสรรสินค้าที่มีอยู่ตามสินค้า ล็อต พาเลท และตำแหน่ง
4. ตรวจสอบว่าจำนวนที่จัดสรรไม่เกินจำนวนที่พร้อมใช้งาน

## การหยิบสินค้า (Picking)

1. เปิดหน้า Picking
2. ตรวจสอบเอกสารหยิบและรายการสินค้า
3. หยิบสินค้าให้ตรงกับล็อต พาเลท และตำแหน่ง
4. หากพบของขาด ของเสีย หรือหยิบไม่ได้ ให้แจ้งผู้จัดการคลัง

## การจ่ายสินค้าออก (Dispatch / Goods Issue)

1. เปิดหน้า Dispatch / Goods Issue
2. ตรวจสอบคำขอเบิกและเอกสาร picking ที่เกี่ยวข้อง
3. ตรวจสอบสินค้าที่โหลดออกให้ตรงกับรายการหยิบ
4. ดำเนินการ Goods Issue เฉพาะเมื่อข้อมูลพร้อมและอยู่ใน workflow ที่อนุมัติแล้ว
5. ตรวจสอบยอด stock ลดลงและ movement ledger ถูกต้อง

## การตรวจสอบ Movement Ledger

- ค้นหาด้วยเลขอ้างอิงเอกสาร
- ตรวจสอบประเภท movement ลูกค้า สินค้า ล็อต พาเลท จำนวน คลัง และตำแหน่ง
- ใช้ movement ledger เป็นหลักฐานการตรวจสอบย้อนหลัง

## ข้อผิดพลาดที่พบบ่อย

- เลือกสินค้าผิดลูกค้า
- เลือกล็อตหรือพาเลทผิด
- ระบุจำนวนหรือหน่วยนับผิด
- ย้ายสินค้าจริงก่อนตรวจสอบข้อมูลในระบบ
- ไม่ตรวจสอบ movement ledger หลังทำรายการ

## Evidence / Record-keeping

- เลขอ้างอิงรายการหรือเอกสาร
- ภาพหน้าจอหรือหลักฐานก่อนและหลังทำรายการ
- เลขอ้างอิง movement ledger
- หลักฐาน stock balance
- ชื่อผู้ปฏิบัติงานและเวลา
- ผู้ตรวจสอบหรือผู้อนุมัติในกรณีที่เกี่ยวข้อง

## Control Points

- สินค้าของลูกค้าต้องตรวจสอบย้อนกลับได้
- ต้องตรวจสอบจำนวน ล็อต พาเลท และตำแหน่งก่อนยืนยัน
- รายการผิดปกติต้องส่งให้ผู้จัดการคลังตรวจสอบ
- รายการที่มีผลต่อ stock ต้องตรวจสอบในรายงานและ movement ledger
